# 애호박 새우젓 볶음

> 재료가 다섯 개뿐이라 숨을 곳이 없다. 애호박이 물러지면 끝이다.
> **소금 대신 새우젓으로 간을 하는 이유**를 이해하면 이 요리는 실패하지 않는다.

| 항목 | 내용 |
|---|---|
| 조리 시간 | 10분 |
| 분량 | 2인분 (반찬 기준) |
| 난이도 | 하 |
| 핵심 기술 | 두께 균일하게 썰기, 물 나오기 전에 끝내기 |

---

## 재료

### 기본
| 재료 | 계량 | 메모 |
|---|---|---|
| 애호박 | 1개 (250g) | 단단하고 표면에 윤기 있는 것 |
| 새우젓 | 1작은술 | 국물까지 함께. 건더기는 잘게 다진다 |
| 다진 마늘 | 1/2큰술 | |
| 식용유 | 1큰술 | |
| 참기름 | 1/2큰술 | **불 끄고** 넣는다 |
| 통깨 | 1작은술 | |

### 있으면 좋은 것
- 대파 1/2대 (어슷썰기)
- 홍고추 1/2개 (색 대비용)
- 양파 1/4개
- 물 1큰술 (수분이 부족할 때만)

> **왜 소금이 아니라 새우젓인가**
> 소금은 삼투압으로 애호박에서 물을 확 빼내 축 처지게 만든다.
> 새우젓은 짠맛에 더해 아미노산 감칠맛이 있어서, **적은 양으로 간이 맞는다.**
> 넣는 소금의 절대량이 줄어드니 애호박이 덜 무르고 아삭함이 남는다.
> 새우젓 특유의 냄새는 마늘과 열이 대부분 날려준다.

---

## 도구
- 넓은 팬 (애호박이 한 겹으로 깔릴 정도)
- 도마, 칼

| 시간 | 할 일 |
|---|---|
| 0:00–3:00 | 애호박 썰기, 새우젓 다지기 |
| 3:00–4:00 | 마늘 향 내기 |
| 4:00–7:00 | 애호박 볶기 |
| 7:00–9:00 | 새우젓으로 간 |
| 9:00–10:00 | 참기름·통깨 마무리 |

## 만드는 법

### 1. 애호박 썰기 (0:00–3:00)
애호박을 **세로로 반 가른 뒤, 0.5cm 두께의 반달 모양**으로 썬다.

- **두께가 균일한 게 전부다.** 두꺼운 조각과 얇은 조각이 섞이면 얇은 건 물러지고 두꺼운 건 설익는다.
- 0.5cm보다 얇으면 볶는 동안 뭉개진다. 두꺼우면 겉만 익고 속이 아삭하다 못해 설익는다.
- 씨 부분이 유난히 무른 애호박이라면 씨를 숟가락으로 살짝 긁어낸다.
- **소금에 절이지 않는다.** 절이면 물이 빠져 볶는 게 아니라 삶는 게 된다.

### 2. 새우젓 손질 (0:00–3:00)
새우젓 1작은술을 도마에서 칼로 **잘게 다진다.** 국물은 버리지 말고 함께 쓴다.

- 통째로 넣으면 그 조각을 씹은 사람만 짠맛 폭탄을 맞는다.
- 다지면 간이 전체에 고르게 퍼진다.

### 3. 마늘 향 내기 (3:00–4:00)
팬에 식용유 1큰술을 두르고 **중불**로 달군 뒤 다진 마늘을 넣는다.

- 30초~1분. 마늘이 노릇해지기 직전, 향이 확 올라오면 다음 단계.
- 대파를 쓸 거면 여기서 함께 넣어 파기름을 낸다.

### 4. 애호박 볶기 (4:00–7:00)
애호박을 넣고 **중불에서 3분** 볶는다.

- 처음 1분은 **건드리지 않는다.** 팬에 닿은 면이 살짝 노릇해져야 고소한 맛이 생긴다.
- 그다음부터 뒤집개로 크게 몇 번만 뒤집는다. 계속 휘저으면 부서진다.
- 애호박 표면이 반투명해지고 가장자리에 옅은 갈색이 생기면 알맞다.
- **팬이 좁아 애호박이 겹쳐 쌓이면 물이 나온다.** 한 겹으로 깔리는 넓은 팬을 쓰거나 두 번에 나눠 볶는다.

> 애호박은 90%가 수분이다. 오래 볶으면 반드시 물이 나온다.
> 물이 나오기 **전에** 끝내는 게 이 요리의 시간 싸움이다. 3분이 마지노선.

### 5. 새우젓으로 간 (7:00–9:00)
다진 새우젓을 넣고 **1분만** 더 볶는다.

- **소금은 넣지 않는다.** 새우젓이 이미 짜다.
- 맛을 보고 싱거우면 새우젓을 1/3작은술씩 추가한다. 한 번에 넣지 않는다.
- 팬이 너무 말랐으면 물 1큰술을 넣어 눌어붙은 것을 긁어 섞는다.

### 6. 마무리 (9:00–10:00)
**불을 끄고** 참기름 1/2큰술과 통깨를 넣어 섞는다.

> 참기름을 불이 켜진 상태에서 넣으면 향이 날아가고 쓴맛이 남는다.
> 잔열에 섞는 것만으로 향은 충분히 퍼진다.

## 실패 진단표

| 증상 | 원인 | 해결 |
|---|---|---|
| 물이 흥건하다 | 너무 오래 볶음 / 팬이 좁아 겹쳐 쌓임 | 3분 안에 끝내기, 넓은 팬에 한 겹으로 |
| 축 처지고 물컹하다 | 소금에 절였거나 소금 추가 | 절이지 말고, 간은 새우젓만으로 |
| 설익어 풋내가 난다 | 너무 두껍게 썰거나 볶는 시간 부족 | 0.5cm 균일하게 |
| 부서졌다 | 계속 휘저음 | 처음 1분 방치 후 크게 몇 번만 뒤집기 |
| 짜다 | 새우젓을 한 번에 다 넣음 | 절반 넣고 맛본 뒤 추가 |
| 참기름 맛이 쓰다 | 불 위에서 넣음 | 불 끄고 잔열에 넣기 |
| 새우젓 냄새가 난다 | 마늘 향 내기를 생략 | 마늘을 먼저 충분히 볶기 |

---

## 응용

- **새우젓 없이:** 국간장 1작은술 + 소금 한 꼬집. (감칠맛은 덜하다)
- **들깨 버전:** 마지막에 들깻가루 1큰술 + 물 2큰술. 부드러운 나물 느낌이 된다.
- **매콤하게:** 청양고추 1개 어슷썰기를 4단계에 추가.
- **국물 요리로:** 물 1컵을 붓고 끓이면 애호박 새우젓국이 된다.
- **볶음밥 재료로:** 잘게 썰어 볶은 뒤 밥과 계란을 넣으면 애호박 볶음밥.

## 보관
밀폐용기에 담아 **냉장 2~3일.**
식으면 물이 조금 나오는데 정상이다. 먹기 전 그 물째로 팬에 살짝 데우면 다시 맛이 산다.
전자레인지로 데우면 물러지니 팬을 권한다.
