# 레시피북 — 맛있는 15분 요리

## 15분 요리 성공 공식

| 원칙 | 내용 | 해당 레시피 |
|---|---|---|
| **미장플라스** | 불을 켜기 전에 모든 재료 손질과 양념 계량을 끝낸다 | 01, 02, 07 |
| **동시 진행** | 물 끓이기·면 삶기는 다른 작업과 병행한다 | 02, 03 |
| **재료 최소화** | 5가지 이하로 구성한다 | 05 |
| **간은 마지막에** | 짠맛은 되돌릴 수 없으니 절반만 넣고 맛본 뒤 더한다 | 전부 |
| **물기 제거** | 물기가 남으면 양념이 희석돼 아무리 넣어도 밍밍하다 | 02, 04, 06 |
| **한 팬, 한 볼** | 설거지가 늘면 다음에 안 하게 된다 | 01, 05 |

## 공통 실패 원인 톱 3

1. **물기를 안 뺐다** — 면, 채소, 양파. 간이 안 맞는 원인의 대부분이다.
2. **불이 셌다** — 마늘·버터·간장은 모두 중불 이하가 기본. 타면 쓴맛만 남는다.
3. **양념을 한 번에 다 넣었다** — 절반만 넣고 맛보는 습관 하나로 실패가 절반 줄어든다.
