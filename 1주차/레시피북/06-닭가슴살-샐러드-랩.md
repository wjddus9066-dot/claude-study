# 닭가슴살 샐러드 랩

> 불을 거의 안 쓰고, 도시락으로 싸도 되고, 손으로 먹는다.
> 관건은 맛보다 **구조**다. 말다가 터지고 먹다가 흘러내리는 걸 막는 순서가 정해져 있다.

| 항목 | 내용 |
|---|---|
| 조리 시간 | 12분 |
| 분량 | 2인분 (랩 2개) |
| 난이도 | 하 |
| 핵심 기술 | 수분 차단 레이어링, 말기 |

---

## 재료

### 기본
| 재료 | 계량 | 메모 |
|---|---|---|
| 조리된 닭가슴살 | 1팩 (150g) | 시판 훈제/스팀 제품. 플레인보다 허브맛이 낫다 |
| 또띠아 | 2장 (8~10인치) | 8인치는 빡빡하다. **10인치 권장** |
| 양상추 | 4~5장 | 로메인도 좋다 |
| 파프리카 | 1/2개 | 색과 아삭함 담당 |
| 슬라이스 치즈 | 2장 | **방수층 역할.** 생략하면 안 된다 |
| 머스터드 | 1큰술 | 홀그레인이면 식감이 산다 |
| 마요네즈 | 1큰술 | |

### 있으면 좋은 것
- 적양파 1/8개 (얇게 슬라이스, 찬물 30초)
- 오이 1/4개 (씨 제거 필수)
- 아보카도 1/2개
- 할라피뇨
- 후추, 꿀 1작은술

> **소스 배합:** 머스터드 1 : 마요네즈 1이 기본.
> 느끼하면 머스터드를 늘리고, 아이가 먹으면 꿀 1작은술을 더한다.

## 만드는 법

### 1. 채소 물기 빼기 (0:00–4:00)
양상추를 씻어 **키친타월로 눌러 물기를 완전히 없앤다.** 파프리카는 채 썬다.

- 물기가 남으면 또띠아가 눅눅해져 말 때 찢어진다. 이 요리의 1번 실패 원인.
- 양상추는 칼로 자르지 말고 **손으로 찢는다.** 칼로 자른 단면은 금방 갈변하고 물이 나온다.
- 오이를 쓸 거면 **숟가락으로 씨를 파낸다.** 씨가 물의 주범이다.
- 적양파는 찬물에 30초 담갔다 물기를 짠다.

### 2. 닭가슴살 준비 (4:00–6:00)
결대로 손으로 찢거나 1cm 두께로 썬다.

- 찢는 쪽이 소스가 잘 배고 씹는 느낌이 부드럽다.
- 차가우면 맛이 덜하니 전자레인지 20초만 돌린다. 오래 돌리면 퍽퍽해진다.
- 볼에 닭가슴살 + 후추를 넣고 살짝 버무려둔다.

### 3. 소스 섞기 (4:00–6:00)
작은 그릇에 머스터드 1큰술 + 마요네즈 1큰술을 섞는다. 후추를 넉넉히.

### 4. 또띠아 데우기 (6:00–8:00)
**기름 없이 마른 팬**에 중불로 앞뒤 20초씩 데운다.

- 데우지 않은 또띠아는 말 때 갈라진다. 열이 글루텐을 유연하게 만든다.
- 20초를 넘기면 바삭해져서 오히려 더 잘 부러진다. **부드러워지기만 하면 끝.**
- 전자레인지를 쓸 거면 젖은 키친타월로 감싸 10초.

### 5. 레이어링 — 순서가 정해져 있다 (8:00–10:00)
또띠아를 펴고 **가운데 아래쪽 1/3 지점**에 재료를 가로로 길게 놓는다.

```
① 소스        또띠아 중앙에 얇게 펴 바른다 (가장자리 2cm는 비워둔다)
② 슬라이스 치즈  소스 위에 깐다  ← 방수층
③ 닭가슴살      치즈 위에
④ 파프리카·양파  그 위에
⑤ 양상추        맨 위 ← 완충층
```

> **왜 이 순서인가**
> 치즈가 아래에 깔려 소스와 재료 수분이 또띠아에 직접 닿는 걸 막는다.
> 양상추를 맨 위에 두면 말았을 때 바깥쪽에서 눌리며 속을 잡아준다.
> 순서를 바꾸면 30분 뒤 도시락을 열었을 때 또띠아 바닥이 젖어 있다.

- **가장자리 2cm는 반드시 비운다.** 재료가 끝까지 차 있으면 접을 여유가 없어 터진다.
- 재료를 높이 쌓지 말고 **가로로 길게 눕힌다.** 두께가 3cm를 넘으면 못 만다.

### 6. 말기 (10:00–11:00)
1. **아래쪽**을 재료 위로 접어 올려 꾹 누른다.
2. **양옆**을 안쪽으로 접는다. (이 단계를 빼면 옆으로 다 흘러나온다)
3. 아래쪽을 잡고 **앞으로 굴리며** 단단히 만다.

- 굴릴 때 손바닥으로 속을 눌러가며 말아야 빈틈이 없다.
- 다 말았으면 이음매가 **아래로 가게** 놓는다. 무게로 눌려 붙는다.

### 7. 자르기 (11:00–12:00)
**종이호일로 랩 전체를 감싼 뒤** 톱질하듯 대각선으로 반 자른다.

- 종이호일 없이 자르면 속이 밀려 나온다.
- 도시락이면 종이호일째로 담는다. 그대로 벗겨가며 먹으면 손이 안 더러워진다.

## 실패 진단표

| 증상 | 원인 | 해결 |
|---|---|---|
| 말다가 찢어진다 | 또띠아를 안 데움 | 마른 팬에 20초씩 |
| 바닥이 눅눅하다 | 치즈 방수층 생략 / 채소 물기 | 치즈를 소스 바로 위에, 채소는 물기 완전 제거 |
| 옆으로 흘러나온다 | 양옆을 안 접음 | 아래 → 양옆 → 굴리기 순서 준수 |
| 터진다 | 속을 너무 많이/높게 넣음 | 두께 3cm 이하, 가장자리 2cm 비우기 |
| 자를 때 속이 밀린다 | 그냥 자름 | 종이호일로 감싸고 톱질하듯 |
| 퍽퍽하다 | 닭가슴살을 오래 데움 | 20초만, 소스를 조금 더 |
| 양상추가 축 처졌다 | 칼로 자름 | 손으로 찢기 |

## 응용

- **매콤 버전:** 소스에 스리라차 1작은술, 할라피뇨 추가.
- **한식 버전:** 소스를 쌈장 1/2큰술 + 마요네즈 1큰술로. 깻잎을 치즈 대신 방수층으로.
- **저탄수:** 또띠아 대신 큰 양상추 잎 2장으로 감싼다.
- **든든하게:** 밥 3큰술 또는 삶은 병아리콩을 추가.
- **아침 도시락:** 전날 밤에 만들어 종이호일에 싸두면 아침에 그대로 들고 나간다.

## 보관
종이호일에 단단히 싸서 **냉장 하루**까지는 형태가 유지된다.
그 이상은 양상추가 숨이 죽는다.
미리 만들 거라면 **양상추만 빼고** 말아두었다가 먹기 직전에 끼워 넣는 방법도 있다.
