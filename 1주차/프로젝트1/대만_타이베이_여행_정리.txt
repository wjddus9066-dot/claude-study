========================================
    대만 타이베이(台北) 여행 정리
    작성일: 2026-08-27
========================================

[1] 기본 정보
----------------------------------------
- 국가/도시 : 대만(Taiwan) / 타이베이(Taipei)
- 비행시간   : 인천 → 타오위안공항 약 2시간 30분 (부담 없는 단거리)
- 시차       : 한국보다 1시간 느림 (한국 12시 = 대만 11시)
- 화폐       : 대만달러(NTD, 元) / 1 NTD ≈ 약 45원
- 언어       : 중국어(번체) / 관광지·MRT는 영어 표기 잘 되어 있음
- 비자       : 한국인 90일 무비자
- 전압       : 110V (돼지코 어댑터 필요)
- 치안       : 매우 좋은 편, 야간 이동도 무난

[2] 여행 적기
----------------------------------------
- 최적기 : 3~4월(봄, 벚꽃), 10~12월(가을~초겨울, 가장 쾌적)
- 피할 때 : 6~9월 (고온다습 + 태풍 시즌, 체감 40도 육박)
- 겨울   : 춥진 않지만 비가 잦고 습함 (얇은 겉옷 + 우산 필수)
- 기후   : 아열대성. 여름엔 스콜성 소나기 잦으니 우산 상시 휴대

[3] 교통
----------------------------------------
■ 공항 → 시내
  - 공항 MRT : 약 35~50분, 편도 150 NTD 내외 (가성비 최고)
  - 공항버스 : 짐 많을 때 추천, 1시간 내외
  - 택시     : 1,000~1,300 NTD 수준

■ 시내 교통 - MRT(지하철)
  - 6개 노선, 운행 06:00 ~ 24:00, 배차 2~6분
  - 요금 20~65 NTD, 청결하고 정시성 높음
  - ※ 차내 음식물 섭취 금지 (물도 포함, 벌금 대상)

■ 이지카드(悠遊卡 / EasyCard) — 3일 이상 체류 시 강력 추천
  - 보증금 100 NTD(환불 불가) + 충전 금액
  - MRT 20% 할인, 버스 환승 할인, 유바이크(YouBike) 이용 가능
  - 편의점(세븐일레븐, 패밀리마트) 결제도 가능
  - 구매처 : 공항, 모든 MRT역, 편의점

■ 2026년 신규
  - 2026년 7월 1일부터 타이베이 MRT 개찰구에서 실물 신용카드/
    모바일 지갑 비접촉 결제(태그) 가능

[4] 시내 필수 코스
----------------------------------------
1. 타이베이 101
   - 508m 랜드마크, 89층 전망대 + 지하 푸드코트/딘타이펑
   - 해질녘~야경 시간대 방문 추천

2. 융캉제(永康街)
   - 미식 거리. 딘타이펑 본점, 망고빙수(스무시하우스), 우육면
   - 카페·소품샵 많아 걷기 좋음

3. 시먼딩(西門町)
   - 타이베이의 명동. 쇼핑, 길거리 음식, 젊은 분위기

4. 야시장
   - 스린 야시장  : 규모 최대, 관광객 필수 코스
   - 라오허제 야시장 : 맛집 밀집, 후추빵(호초병) 유명
   - 닝샤 야시장  : 로컬 감성, 먹거리 집중형

5. 중정기념당 / 국립고궁박물원
   - 중정기념당 : 위병 교대식(매시 정각) 볼거리
   - 고궁박물원 : 취옥백채, 육형석 등 중화권 최대 컬렉션

6. 룽산사(용산사)
   - 타이베이 최고(最古) 사찰, 야경도 예쁨

[5] 근교 인기 코스
----------------------------------------
■ 예스진지 (예류 + 스펀 + 진과스 + 지우펀)
  - 타이베이 여행의 정석 1일 투어
  - 예류지질공원 : 여왕머리 기암괴석
  - 스펀        : 천등(풍등) 날리기 + 스펀폭포
  - 진과스      : 황금박물관, 옛 광산마을
  - 지우펀      : 홍등 골목 야경 (해질녘 도착이 베스트)
  - ※ 개별 이동보다 현지 1일 투어(KKday/클룩) 예약이 훨씬 편함

■ 그 외
  - 베이터우 온천 : MRT로 접근 가능한 시내 온천
  - 단수이(담수)  : 노을 명소 + 어인부두
  - 마오콩 곤돌라 : 차밭 전망 케이블카
  - 허우통 고양이마을 / 핑시선 기차 여행
  - 이란(宜蘭)    : 차로 1시간, 최근 뜨는 고급 휴양지

[6] 먹거리 리스트
----------------------------------------
- 우육면(牛肉麵)     : 대만 국민 음식
- 샤오롱바오          : 딘타이펑, 가오지
- 루로우판(魯肉飯)   : 저렴하고 든든한 덮밥
- 망고빙수            : 여름 시즌 필수
- 지파이(대왕 치킨)  : 야시장 대표 간식
- 버블티              : 춘수당, 50람, 코코 등
- 후추빵(호초병)     : 라오허제 야시장 명물
- 취두부              : 도전 메뉴

[7] 예산 가이드 (1인 기준, 3박 4일)
----------------------------------------
- 항공권   : 25~50만원 (시즌/LCC에 따라 편차 큼)
- 숙박     : 1박 7~15만원 (중급 호텔 기준)
- 식비     : 1일 3~5만원 (로컬 위주면 더 저렴)
- 교통     : 1일 5천원 내외
- 총합     : 약 70~110만원 수준

[8] 여행 팁
----------------------------------------
- 현금 : 야시장·로컬 식당은 현금 위주. 환전은 현지 공항/은행이 유리
- 물   : 수돗물 음용 불가, 생수 구매
- 팁   : 팁 문화 없음 (일부 식당 10% 봉사료 자동 부과)
- 편의점 : 세븐일레븐/패밀리마트 밀집도 높아 매우 편리
- 유심 : 공항에서 무제한 유심 저렴하게 구입 가능 (5일 300 NTD 내외)
- 우산 : 사계절 상시 휴대 (비 + 햇빛 겸용)
- 앱   : Google Maps, Bus+ (버스), KKday/클룩 (투어 예약)

[9] 3박 4일 추천 일정
----------------------------------------
Day 1 : 도착 → 숙소 체크인 → 시먼딩 → 닝샤 야시장
Day 2 : 중정기념당 → 융캉제(딘타이펑·망고빙수) → 타이베이101
        → 라오허제 야시장
Day 3 : 예스진지 1일 투어 (예류-스펀-진과스-지우펀)
Day 4 : 베이터우 온천 or 국립고궁박물원 → 쇼핑 → 출국
