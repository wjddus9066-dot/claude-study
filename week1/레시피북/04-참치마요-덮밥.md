# 참치마요 덮밥

> 불을 쓰는 시간이 계란 부치는 2분뿐이다. 이 책에서 가장 빠른 메뉴.
> 대신 **참치 기름을 얼마나 짜내느냐**로 완성도가 통째로 갈린다.

| 항목 | 내용 |
|---|---|
| 조리 시간 | 7분 |
| 분량 | 1인분 |
| 난이도 | 하 |
| 핵심 기술 | 참치 탈유, 양파 매운맛 제거 |

---

## 재료

### 기본
| 재료 | 계량 | 메모 |
|---|---|---|
| 따뜻한 밥 | 1공기 (210g) | |
| 참치캔 | 1개 (100g, 살코기) | 기름 제거 후 실중량 약 70g |
| 마요네즈 | 2큰술 | 일본식(큐피 등)이 산미가 강해 더 어울린다 |
| 양파 | 1/4개 | 잘게 다지기 |
| 진간장 | 1작은술 | |
| 설탕 | 1/2작은술 | 마요네즈의 산미를 잡아준다 |
| 계란 | 1개 | 반숙 프라이 |
| 김가루 | 한 줌 | |

### 있으면 좋은 것
- 쪽파 1대
- 스리라차 또는 청양고추
- 슬라이스 치즈 1장
- 참기름 1/2작은술
- 후추

---

## 도구
- 작은 볼
- 숟가락 (참치 기름 짜는 용도로 캔 뚜껑을 써도 된다)
- 프라이팬

---

## 타임라인

| 시간 | 할 일 |
|---|---|
| 0:00–1:00 | 밥 데우기 시작, 양파 다지기 |
| 1:00–2:00 | 양파 찬물에 담그기 + 참치 기름 짜기 |
| 2:00–3:00 | 참치마요 섞기 |
| 3:00–5:00 | 계란 반숙 프라이 |
| 5:00–7:00 | 담고 고명 |

---

## 만드는 법

### 1. 밥과 양파 (0:00–1:00)
밥을 데우기 시작한다. 양파 1/4개를 **최대한 잘게** 다진다.

- 참치 살보다 크면 씹을 때 양파만 도드라진다. 참치 결과 비슷한 크기가 목표.

### 2. 양파 매운맛 빼기 (1:00–2:00)
다진 양파를 **찬물에 30초** 담갔다가 체에 밭쳐 물기를 꼭 짠다.

> 생양파의 매운맛 성분은 물에 녹는다. 30초면 충분하고, 3분 넘게 담그면
> 단맛까지 빠져나가 아무 맛도 안 나는 아삭함만 남는다.
> 물기를 안 짜면 참치마요가 묽어진다.

### 3. 참치 기름 짜기 — 이 요리의 핵심 (1:00–2:00)
캔 뚜껑을 반쯤 열어 **꾹 눌러 기름을 완전히 따라낸다.**

- 한 번 따르고 끝내지 말고, 30초 세워 남은 기름을 더 뺀다.
- 기름이 많이 남으면: 마요네즈가 겉돌고, 밥이 느끼해지고, 간장이 스며들지 않는다.
- 더 확실하게: 체에 받쳐 숟가락으로 눌러 짠다. 기름진 게 싫으면 뜨거운 물을 한 번 끼얹는다.

> **기름 vs 물 참치:** 물 참치를 쓰면 이 과정이 훨씬 쉽지만 고소함이 줄어든다.
> 기름 참치를 쓰고 확실히 짜는 쪽이 맛있다.

### 4. 참치마요 섞기 (2:00–3:00)
볼에 참치 + 물기 짠 양파 + 마요네즈 2큰술 + 간장 1작은술 + 설탕 1/2작은술.

- 숟가락으로 **참치 결을 살짝 으깨듯** 섞는다. 너무 곱게 갈면 식감이 사라진다.
- 후추를 넉넉히. 참치 비린내를 잡는 건 후추다.
- 맛보고 싱거우면 간장 몇 방울. 짜면 마요네즈를 더한다.

### 5. 계란 반숙 프라이 (3:00–5:00)
팬에 기름을 두르고 **약불**에서 계란 1개를 반숙으로 부친다.

- 뚜껑을 덮으면 노른자 표면만 살짝 익어 모양이 예쁘다.
- 흰자 가장자리가 바삭해질 정도가 좋다. 참치마요가 부드러우니 대비가 필요하다.

### 6. 담기 (5:00–7:00)
그릇에 밥 → **참치마요를 밥 전체에 고르게** → 계란 → 김가루 → 쪽파.

- 참치마요를 가운데만 쌓으면 가장자리 밥이 맨밥으로 남는다. 펴 바른다.
- 치즈를 쓸 거면 뜨거운 밥 위에 먼저 올려 녹인 뒤 참치마요를 얹는다.

### 7. 먹기
노른자를 터뜨려 비빈다. 스리라차를 지그재그로 뿌리면 마요네즈의 느끼함이 잡힌다.

---

## 실패 진단표

| 증상 | 원인 | 해결 |
|---|---|---|
| 느끼하다 | 참치 기름을 덜 짬 | 캔을 눌러 완전히 따라내고 30초 더 세워두기 |
| 묽어서 흘러내린다 | 양파 물기를 안 짬 | 찬물에서 건진 뒤 손으로 꼭 짜기 |
| 양파가 맵다 | 물에 안 담금 | 찬물 30초 |
| 비린내가 난다 | 후추 부족 | 후추 넉넉히 + 간장 몇 방울 |
| 밥이 뻑뻑하다 | 참치마요가 가운데만 쌓임 | 밥 전체에 펴 바르기 |
| 맛이 밋밋하다 | 설탕을 뺌 | 설탕 1/2작은술이 마요 산미를 잡아준다 |

---

## 응용

- **삼각김밥 속:** 물기를 더 확실히 짜고 밥에 소금·참기름 간을 해서 김에 싼다.
- **매콤 참치마요:** 스리라차 1작은술 또는 고추장 1/2작은술 추가.
- **오븐 버전:** 밥 위에 참치마요 + 치즈를 얹고 에어프라이어 180도 5분. 그라탕이 된다.
- **샌드위치:** 식빵에 그대로. 오이 슬라이스를 넣으면 수분감이 산다.
- **덜 느끼하게:** 마요네즈 1큰술 + 플레인 요거트 1큰술로 대체.

| 김가루 | 조미김 3장 부수기 |

## 보관
참치마요만 밀폐용기에 담아 **냉장 2일**. 그 이상은 양파에서 물이 나와 묽어진다.
만들어두면 아침에 밥 위에 얹기만 하면 되니 주말에 2배로 만들어두면 편하다.
계란은 그때그때 부친다.
