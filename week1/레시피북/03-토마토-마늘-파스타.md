# 토마토 마늘 파스타

> 소스를 따로 만들지 않는다. **방울토마토를 팬에서 터뜨려 그 자리에서 소스가 된다.**
> 15분 안에 끝내는 유일한 방법은 면 삶기와 소스 만들기를 **동시에** 돌리는 것이다.

| 항목 | 내용 |
|---|---|
| 조리 시간 | 15분 |
| 분량 | 2인분 |
| 난이도 | 중 |
| 핵심 기술 | 병렬 진행, 마늘 저온 인퓨징, 면수 유화 |

---

## 재료

### 기본
| 재료 | 계량 | 메모 |
|---|---|---|
| 스파게티 면 | 160g (1인 80g) | 두께 1.7mm 기준. 1.9mm면 삶는 시간 +1분 |
| 방울토마토 | 15~18알 (250g) | 완숙일수록 좋다. 단맛이 소스의 전부다 |
| 마늘 | 5쪽 | **편 썰기.** 다지면 탄다 |
| 올리브유 | 3큰술 | 엑스트라 버진 |
| 소금 | 면수용 1큰술 + 간 맞추기용 약간 | |
| 후추 | 약간 | 마지막에 갓 갈아서 |

### 있으면 좋은 것
- 파르메산 치즈 2큰술
- 바질 잎 5장 (없으면 생략, 말린 바질은 향이 다르다)
- 페페론치노 2개 또는 건고추
- 버터 1작은술 (마무리 광택용)

> **면수 소금 1큰술이 왜 필요한가:** 파스타에 간이 들어가는 유일한 순간이다.
> 물 2L에 소금 1큰술이면 "바닷물보다 살짝 싱거운" 정도. 여기서 간을 안 하면
> 나중에 소스를 아무리 짜게 해도 면 자체는 계속 밍밍하다.

---

## 도구
- 큰 냄비 (물 2L)
- 넓은 팬 (28cm 이상 — 면을 팬에서 섞어야 한다)
- 집게 또는 파스타 서버
- 국자 (면수용)

---

## 타임라인 — 병렬 진행이 핵심

| 시간 | 냄비 (면) | 팬 (소스) |
|---|---|---|
| 0:00–3:00 | 물 올리기, 소금 투입 | 마늘 편 썰기, 토마토 반 자르기 |
| 3:00–4:00 | **면 투입** | 올리브유 + 마늘 약불 시작 |
| 4:00–7:00 | 삶는 중 | 마늘 향 내기 → 토마토 투입 |
| 7:00–10:00 | 삶는 중 | 토마토 으깨며 볶기 |
| 10:00–11:00 | **면 건지기 (표시 -1분)** | 면수 1국자 투입 |
| 11:00–13:00 | — | 면 + 소스 센 불에 볶기 |
| 13:00–15:00 | — | 간 맞추고 담기 |

> 면 삶는 시간을 소스에 맞추는 게 아니라, **소스를 면 시간에 맞춘다.**
> 면이 다 됐는데 소스가 안 됐으면 면이 퍼진다. 소스가 먼저 완성되는 게 정상이다.

---

## 만드는 법

### 1. 물부터 올린다 (0:00)
물 2L를 센 불에 올리고 뚜껑을 덮는다. 끓으면 소금 1큰술.

### 2. 물 끓는 동안 손질 (0:00–3:00)
- 마늘 5쪽을 **0.2cm 두께로 편 썬다.** 두꺼우면 안 익고, 얇으면 탄다.
- 방울토마토를 **세로로 반** 자른다. 단면이 팬에 닿아야 즙이 빨리 나온다.
- 치즈를 갈아두고, 바질을 씻어둔다.

### 3. 면 투입 (3:00)
물이 팔팔 끓으면 면을 넣는다. **여기서부터 시계를 본다.**
넣고 30초간 저어 붙는 걸 막는다. 포장 표시가 8분이면 **7분에 건진다.**

### 4. 마늘 향 내기 (3:00–6:00)
면을 넣자마자 팬으로 간다. 차가운 팬에 올리브유 3큰술과 마늘 편을 **동시에** 넣고 약불을 켠다.

- **차가운 팬에서 시작하는 게 맞다.** 달군 팬에 넣으면 겉만 타고 향이 안 나온다.
- 기름에 잔거품이 올라오며 마늘 가장자리가 연한 금색이 되면 끝. 3분 정도.
- 마늘이 진한 갈색이 되면 쓴맛이 난다. **금색에서 멈춘다.**
- 페페론치노를 쓸 거면 마늘이 반쯤 익었을 때 부숴 넣는다.

### 5. 토마토 볶기 (6:00–10:00)
불을 중불로 올리고 방울토마토를 **자른 단면이 아래로 가게** 넣는다.

- 처음 1분은 건드리지 않는다. 단면이 지져지며 단맛이 응축된다.
- 그다음 뒤집개나 국자 뒷면으로 **하나씩 눌러 터뜨린다.** 즙이 나오면서 소스가 된다.
- 소금 한 꼬집을 여기서 넣으면 토마토에서 수분이 더 빨리 빠진다.
- 3~4분 후 걸쭉해지고 색이 진해지면 완성.

### 6. 면 건지기 + 면수 (10:00–11:00)
**면수를 먼저 국자로 한 컵 떠둔다.** (매년 가장 많이 잊는 단계)
면은 체에 받치지 말고 집게로 바로 팬에 옮긴다. 물기가 조금 딸려와도 괜찮다.

> **면수의 정체:** 면에서 빠져나온 전분 + 소금물이다.
> 이 전분이 기름과 물을 붙여주는 유화제 역할을 한다. 면수 없이는 기름이 겉돌고,
> 소스가 면에 붙지 않고 접시 바닥에 고인다.

### 7. 마무리 볶기 (11:00–13:00)
면수 1국자를 붓고 **불을 센 불로 올린다.**

- 집게로 면을 계속 들었다 놓으며 1~2분 볶는다.
- 소스가 면에 착 감기고 팬 바닥이 거의 마르면 완성.
- 국물이 많으면 30초 더, 뻑뻑하면 면수를 조금씩 추가.
- 불을 끄고 버터 1작은술을 넣어 섞으면 광택이 확 산다.

### 8. 담기 (13:00–15:00)
소금·후추로 간을 맞추고 접시에 **집게로 돌려가며 봉긋하게** 담는다.
파르메산 치즈와 바질을 올린다.

## 실패 진단표

| 증상 | 원인 | 해결 |
|---|---|---|
| 소스가 면에 안 붙고 접시에 고인다 | 면수를 안 넣었거나 볶는 시간 부족 | 면수 1국자 + 센 불 1분 이상 |
| 마늘이 쓰다 | 갈색까지 태움 | 차가운 팬 + 약불, 금색에서 정지 |
| 면이 퍼졌다 | 표시 시간대로 다 삶음 | 표시 -1분에 건지고 팬에서 마무리 |
| 밍밍하다 | 면수에 소금을 안 넣음 | 물 2L당 소금 1큰술 |
| 토마토가 안 터진다 | 덜 익은 토마토 / 불이 약함 | 국자 뒷면으로 눌러 터뜨리기 |
| 기름지다 | 면수 부족으로 유화 실패 | 면수를 더 넣고 센 불에 저어 섞기 |

---

## 응용

- **알리오 올리오:** 토마토를 빼고 마늘·페페론치노만. 면수 비율을 더 늘린다.
- **크림 토마토:** 7단계에서 생크림 3큰술 추가.
- **해산물:** 5단계 전에 새우나 바지락을 볶아 꺼내두고, 마지막에 되돌린다.
- **매콤하게:** 페페론치노 4개 또는 고추기름 1작은술.
- **치즈 리조니:** 면 대신 리조니(쌀 모양 파스타)를 쓰면 숟가락으로 먹는 버전.

## 재료 대체

| 없으면 | 대신 |
|---|---|
| 방울토마토 | 홀토마토 통조림 1/2캔 (수분이 많아 볶는 시간 +2분) |
| 파르메산 | 그라나 파다노, 슬라이스 치즈 1장 |
| 생바질 | 마지막에 올리브유 한 바퀴로 대체 (말린 바질은 비추) |
| 스파게티 | 링귀네, 페투치네 (삶는 시간 확인) |

## 보관
파스타는 재가열하면 면이 뭉개진다. **2인분을 정확히 만들어 바로 먹는 것**이 원칙.
남았다면 면과 소스를 분리해 냉장하고, 다음 날 팬에 물 2큰술과 함께 센 불로 되살린다.
