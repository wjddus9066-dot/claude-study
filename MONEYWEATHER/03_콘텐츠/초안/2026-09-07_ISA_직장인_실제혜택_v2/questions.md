# questions.md — 독자가 궁금해할 질문

작성일: 2026-09-07

조사 후, 글을 쓰기 전에 먼저 만든다. (§21)
독자 기준: 사회초년생. 경제 공부를 원래 좋아하지 않았고 숫자를 보면 눈이 미끄러진다. (글쓰기톤 §2.5)

---

## 1차 — 독자가 실제로 던지는 질문

```text
Q1.  ISA가 도대체 뭐야? 예금이야 주식이야?
Q2.  다들 만들라는데 안 만들면 진짜 손해야?
Q3.  세금을 깎아준다는데, 원래 얼마를 내는 건데?
Q4.  200만원 비과세라는 게 200만원 넣으면 된다는 뜻이야?
Q5.  나는 주식만 하는데 그래도 이득이야?
Q6.  3년 묶인다던데 중간에 돈 필요하면 어떡해?
Q7.  연 2,000만원? 나는 그만큼 넣을 돈이 없는데 의미가 있나?
Q8.  중개형·신탁형·일임형은 뭐가 달라? 뭘 골라야 해?
Q9.  서민형이 좋다는데 나는 해당돼?
Q10. 인터넷에서 4,000만원으로 늘었다던데 진짜야?
Q11. 만기되면 그냥 찾으면 돼?
Q12. 나 같은 사람한테는 별로일 수도 있어?
```

---

## 2차 — 본문에 반영할 질문과 위치

| 질문 | 본문 위치 | 왜 반영하나 |
| --- | --- | --- |
| Q1 | 1장 「ISA가 뭔지부터」 | 제목의 용어를 본문에서 설명 (글쓰기톤 §7.5) |
| Q3 | 2장 「원래는 세금을 얼마나 내는데?」 | **혜택을 이해하려면 기준선이 먼저 필요하다** |
| Q4 | 3장 | 가장 흔한 오해. 「200만원 넣는 게 아니라 200만원 버는 것」 |
| Q5 | 5장 「그런데 국내 주식은 원래 세금이 없다」 | ★ 이 글의 차별화 |
| Q6 | 6장 | 「원금은 뺄 수 있다」는 사실이 잘 안 알려져 있다 |
| Q7 | 6장 | 평균 납입액 710만원 → 한도는 대부분에게 제약이 아니다 |
| Q9 | 3장 표 | 서민형 요건은 직장인 상당수가 해당 |
| Q10 | 8장 「인터넷에 도는 숫자」 | ★ 이 글의 차별화 |
| Q11 | 7장 「덜 알려진 것」 | 연금계좌 전환 |
| Q12 | 9장 | 「이런 사람은 급하지 않다」 — 균형 |

---

## 반영하지 않는 질문

| 질문 | 이유 |
| --- | --- |
| Q2 (안 만들면 손해?) | "손해"라는 프레임 자체가 공포 마케팅에 가깝다 (§23). 질문을 "나한테 뭐가 좋은가"로 바꿔 다룬다 |
| Q8 (유형 선택) | 이 글 하나에 넣으면 초점이 흐려진다. **다음 글 주제로 분리** (§51, seo.md 내부링크 계획) |

## 이 글이 답해야 하는 핵심 질문 (§9)

| 구분 | 이 글의 답 |
| --- | --- |
| WHAT | ISA는 세금을 깎아주는 "계좌 껍데기"다 |
| WHY | 이자·배당소득 15.4%를 200만원까지 0원, 초과분 9.9%로 낮춰준다 |
| SO WHAT | 손익통산까지 더하면 해외 ETF·배당 투자자에게 실제 수십만원 차이가 난다 |
| WHO | 배당·이자·국내상장 해외 ETF에서 수익이 나는 사람. 국내 개별주식만 담는 사람은 효과가 작다 |
| WHEN | 3년이 지나야 혜택이 확정된다 |
| HOW MUCH | 순이익 500만원 기준 일반형 약 47만원, 서민형 약 67만원 (CALC-002) |
| WHAT TO DO | 내 소득이 서민형 요건에 드는지 확인한다 |
