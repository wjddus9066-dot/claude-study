## 시각화 자동 판단 (§19)

```text
표 필요?               YES  (3곳)
차트 필요?             YES  (세금 비교 막대 1개)
인포그래픽 필요?       YES  (3개)
숫자 계산 필요?        YES  (계산 과정을 본문에 코드블록으로 공개)
용어 설명 박스 필요?   NO   (본문 흐름에서 그때그때 풀었다)
한눈에 보는 요약 필요? NO   (§49.3 — 마지막 섹션에 요약을 붙이지 않는다)
```

## 표 3개

| 위치 | 내용 | 왜 표인가 |
| --- | --- | --- |
| 3장 | 일반형·서민형·농어민형 비과세 한도 | 조건 3개 × 항목 2개. 문장으로 쓰면 눈이 미끄러진다 |
| 6장 | ISA 가입 조건 | 항목 5개 나열. 본문에 풀면 문단이 무거워진다 |
| 8장 | 떠도는 숫자 vs 현행 | 좌우 대조가 이 장의 요점 자체 |

표를 연달아 놓지 않았다 (글쓰기톤 §2.5). 각 표 사이에 최소 두 문단이 들어간다.

### 3차 검증에서 뺀 표

3장에 「500만원 벌었을 때 계좌별 세금」 표가 하나 더 있었다. **삭제했다.**

같은 금액(77만원 / 29만 7천원 / 9만 9천원)이 **표 → 코드블록 → 그림** 순으로 세 번 나왔기 때문이다.
표는 결과만, 그림도 결과를 보여줘서 둘이 같은 일을 하고 있었다 (§66.4).

지금은 **계산 과정은 코드블록, 결과는 그림**으로 역할이 나뉜다.
§17의 "계산 과정을 숨기지 않는다"는 코드블록이 지킨다.

### 표 셀에 HTML 태그를 쓰지 않는다

2차 검증에서 서민형 조건을 두 줄로 보이게 하려고 셀 안에 `<br>`을 넣었는데,
`md2html.js`가 이를 이스케이프해서 **화면에 `<br>`이 글자 그대로 나왔다.**

마크다운만 봐서는 보이지 않는다. 3차에서 화면으로 확인하고 잡았다.
셀이 길면 그냥 한 줄로 쓴다. 너비에 맞춰 자동으로 줄바꿈된다.

### IMAGE_02 — 세금 비교 막대
```text
용도: 본문 설명
소스: 04_이미지/2026-09-07_ISA_직장인_실제혜택/_소스/02_세금비교.html
출력: 04_이미지/2026-09-07_ISA_직장인_실제혜택/02_세금비교.png
주제: 같은 500만원, 계좌에 따라 갈리는 세금
근거: numbers.md CALC-002
위치: 3장 계산 코드블록 뒤
캡션: 같은 500만원을 벌어도 어디에 담았느냐로 세금이 갈립니다.
```

막대 높이가 금액에 비례한다. 77만원과 9만 9천원의 차이가 눈으로 보이게 하는 게 목적이다.
축 눈금·단위·출처·"단순 계산" 전제를 그림 안에 넣었다 (§40).

```text
용도: 본문 설명
소스: 04_이미지/2026-09-07_ISA_직장인_실제혜택/_소스/03_손익통산.html
출력: 04_이미지/2026-09-07_ISA_직장인_실제혜택/03_손익통산.png
주제: 일반 계좌는 이익만 본다 / ISA는 바구니 전체를 본다
근거: numbers.md CALC-001
위치: 4장 "같은 투자를 했는데 46만 2천원이 갈립니다." 뒤
```

손익통산은 말로 설명하면 잘 안 와닿는다. 같은 입력(A +300 / B −100)을 두 칸에 놓고
계산 경로가 갈리는 걸 보여주는 게 가장 빠르다.

## 이미지에 쓴 색

전부 `05_자동화/팔레트.js`의 변수만 사용했다. HTML에 색을 직접 적지 않았다 (§41).

| 쓰임 | 변수 |
| --- | --- |
| 바탕 | `--ivory` / 박스는 `--cream` |
| 글자 | `--navy`, 강조는 `--navy-d` |
| 보조 글자 | `--muted` (캡션·출처는 `--muted-l`) |
| 강조 수치 | `--rose` |
| 막대 | `--navy` / `--pink` / `--gold` |
| 강조 박스 | `--gold` 테두리 + `--gold-bg` |

`--pink`와 `--gold`는 막대·테두리·배경으로만 썼다. 글자색으로 쓰지 않았다 (색상.md).

## 만들지 않은 것

| 후보 | 뺀 이유 |
| --- | --- |
| ISA 가입자 수 추이 차트 | 최신 데이터가 2026년 2월 말. 「지금」을 말하기엔 낡았다 (§32.1) |
| 계좌 유형 3종 비교 그림 | 이 글에서 유형 비교를 다루지 않기로 했다 (다음 글로 분리) |
| 편입자산 비중 원그래프 | 독자 질문("나한테 뭐가 좋은가")과 거리가 멀다 |
| 연금계좌 전환 흐름도 | 7장이 짧다. 그림까지 넣으면 무게가 안 맞는다 |

**표를 만들기 위해 데이터를 넣지 않았다** (§1.6).
