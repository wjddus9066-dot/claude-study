## 세 계층으로 나눠 본 점검

전략 문서(`바탕화면/moneyweather 콘텐츠 전략`)의 SEO / AEO / GEO 계층 기준.

### SEO — 검색엔진이 이 글이 무엇에 관한 글인지 아는가

| 항목 | 상태 |
| --- | --- |
| 제목과 본문의 주제 일치 | **PASS** — 예금·고정금리 편을 떼어내 「내 대출이자 반영 시점」 하나로 좁혔다 |
| 소제목이 검색 질문 형태 | **PASS** — 아래 표 참조 |
| 키워드 자연스러운 사용 | PASS |
| 동일 키워드 반복 삽입 | 없음 |
| 검색어 나열 문단 | 없음 |
| 내부 링크 | **0건** — 발행된 글이 없다. 없는 링크를 만들지 않는다 (§66.1) |

**소제목을 전부 질문형으로 바꿨다.** 검색창에 그대로 쳐볼 만한 문장이어야 한다.

| 바꾸기 전 | 바꾼 뒤 |
| --- | --- |
| 일단 기준금리가 뭔지부터 | 기준금리가 뭔가요? |
| 중간에 있는 그 숫자, 이름이 '코픽스'예요 | 코픽스(COFIX)가 뭔가요? |
| 그럼 언제쯤 들어갈까 | 8월 인상은 언제 코픽스에 들어가나요? |
| 그런데 아직 한 번 더 기다려야 해요 | 내 대출금리는 언제 바뀌나요? |
| 그럼 실제로 얼마나 오르는 걸까 | 그래서 이자가 얼마나 더 나가나요? |

### AEO — 사람이 물었을 때 AI가 이 글에서 답을 뽑아갈 수 있는가

| 항목 | 상태 |
| --- | --- |
| 첫 부분에 명확한 답 | **PASS** — 도입 3문장 뒤 `[정답]` 박스 |
| 1~2문장으로 독립적으로 이해되는 답 | **PASS** — 정답 박스 안에서 앞뒤 문맥을 참조하지 않는다 |
| 질문형 소제목 | PASS |
| FAQ | **PASS** — 6문항. 질문 하나에 답 하나가 짝으로 떨어진다 |
| 표·목록으로 구조화 | PASS — 표 3개, 타임라인 1개, 체크리스트 1개 |
| 핵심 숫자·조건 명시 | PASS |

**정답 박스를 앞에 둔 이유가 하나 더 있다.** 티스토리는 목록·홈의 글 요약을
본문 맨 앞에서 긁어간다(§49.3). 도입 세 문장이 요약으로 잡히면
「기준금리 올랐다는 뉴스를 봤는데 이자가 그대로더라」가 보인다. 열어볼 이유가 된다.

### GEO — 생성형 AI가 신뢰할 만한 정보원으로 볼 수 있는가

| 항목 | 상태 |
| --- | --- |
| 정보 출처 명시 | **PASS** — 수치·표마다 인라인 출처 + 원문 링크 |
| 기준일 명시 | **PASS** — 꼬리말과 본문 상단 |
| 원자료 우선 | **PASS** — ECOS 오픈API로 전 항목 직접 대조 (factcheck.md) |
| 주장과 근거 연결 | PASS |
| 전문용어 정의 | **PASS** — 기준금리·코픽스·고정/변동·금리변동주기를 각각 정의 |
| 단정하지 않기 | PASS — "코픽스가 기준금리를 그대로 따라가는 건 아닙니다" 등 |
| 최신·과거 정보 구분 | PASS — 4월분/7월분/8월분을 발표일과 함께 표기 |
| 문맥이 잘려도 의미가 유지되는가 | **PASS** — 정답 박스와 FAQ 각 항목이 단독으로 성립 |

## 떼어낸 내용

전략 문서 §4의 권고에 따라 두 덩어리를 분리했다.
제목은 「내 대출이자」인데 본문이 예금·물가·고정금리 선택까지 번져서,
검색엔진도 AI도 이 글이 무엇에 관한 글인지 흐릿하게 봤다.

| 옮긴 곳 | 무엇 |
| --- | --- |
| `03_콘텐츠/기획/2026-XX-XX_예금금리는_왜_체감이_안될까/` | 예금금리·세후이자·실질금리 |
| `03_콘텐츠/기획/2026-XX-XX_고정금리_갈아타기/` | 고정 vs 변동, 고정금리 비중 |

버린 게 아니라 다음 글 초안으로 옮겼다. 각 폴더에 발행 전 채울 항목을 적어뒀다.

## 내부 링크 (§52)

현재 발행된 글이 없어 내부 링크 **0건**.

**없는 링크를 만들지 않는다.** 제미나이 초안에는 `href="#"` 자리표시자가 있었는데,
그대로 발행하면 깨진 링크가 된다 (§66.1 위반).

발행 순서와 연결 계획:

```text
[기초]  기준금리란?            ← 아직 없음
          ↓
[기초]  코픽스란?              ← 아직 없음
          ↓
[이슈]  이 글 (기준금리 3% → 내 대출이자)     ← 발행 대기
          ↓
[실전]  고정금리로 갈아타야 할까?   ← 기획/ 에 초안 있음
[실전]  예금 이자는 왜 체감이 안 될까?  ← 기획/ 에 초안 있음
```

두 번째 글을 발행하는 시점에 이 글 본문에 링크를 넣는다.
`publish.md` 에 그 작업을 적어둔다.
