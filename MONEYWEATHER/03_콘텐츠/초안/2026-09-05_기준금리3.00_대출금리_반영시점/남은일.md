## 1. 문단 사이 여백이 티스토리에서 죽는다 (제일 급함)

**증상** — 발행하면 문단이 줄줄이 붙어서 한 덩어리로 보인다.
`03_콘텐츠/보안/2026-09-05_.../문단캡쳐 01~03.png` 에 화면이 있다.

**확인한 것**

* 우리가 만든 파일에는 모든 `<p>` 에 `margin:0 0 18px` 가 들어 있다
* 그림(`figure`)과 소제목(`h2`) 여백은 **살아 있다**
* `<p>` 여백만 죽는다
* 스킨(`MAINSKIN/style.css`)은 오히려 `.article-body p{margin:0 0 1.15em}` 로 여백을 준다
  → 스킨이 아직 적용 전이라 기본 스킨에서 눌리는 것으로 보인다

**단서** — 사용자가 붙여준 발행 후 HTML에 티스토리가 붙인 속성이 있었다.

```html
<p style="margin: 0 0 18px;" data-ke-size="size16">
```

`data-ke-*` 는 티스토리 에디터가 본문을 자기 방식으로 다시 쓸 때 붙는다.
즉 **에디터가 본문을 재작성하고 있다.** 여기가 원인일 가능성이 크다.

**해볼 것 (순서대로)**

1. `p` 의 간격을 `margin` 대신 **`padding-bottom`** 으로 바꾼다
   `margin:0; padding:0 0 18px;` — 둘 중 뭐가 살아남든 18px 가 나온다
   (`.src-note` 의 `padding-left` 는 화면에서 살아 있는 것을 확인했다)
2. 그래도 안 되면 티스토리 기본 스킨의 `.tt_article_useless_p_margin` 규칙을 확인한다
3. 최후엔 문단을 `<div>` 로 낸다

**주의** — 고친 뒤 반드시 실제로 붙여넣어 확인한다. 내 렌더링에서는 원래 잘 나온다.
