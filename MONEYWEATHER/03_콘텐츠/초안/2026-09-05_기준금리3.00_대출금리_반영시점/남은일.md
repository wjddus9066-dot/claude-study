## 1. 문단 사이 여백이 티스토리에서 죽는다 — 고침 (2026-09-11), 붙여넣어 확인만 남음

**원인 (확인함)** — 티스토리가 본문을 `.tt_article_useless_p_margin` 으로 감싸고,
블로그가 불러오는 `static/style/uselessPMargin.css` 가 이렇게 누른다.

```css
.tt_article_useless_p_margin p {
    padding-top: 0 !important;  padding-bottom: 0 !important;
    margin-top: 0 !important;   margin-bottom: 0 !important;
}
```

`<p>` 에만 걸리므로 그림·소제목 여백은 살고 문단만 붙었다.
`!important` 라서 인라인 `margin` 도, 스킨의 `.article-body p` 도 진다.
**처음 적어둔 `padding-bottom` 안은 안 된다** — padding 도 같이 누른다.

**고친 것** — `md2html.js` `inlineStyles()` 가 `<p>`·`<figcaption>` 의 margin·padding 에
`!important` 를 붙인다. 인라인 `!important` 는 스타일시트 `!important` 를 이긴다.
(figcaption 은 에디터가 `<p>` 로 바꿔 저장한다. 발행 후 HTML에서 확인)

**검증** — 실제 블로그의 uselessPMargin.css + 스킨 style.css 를 그대로 받아 헤드리스 크롬으로 재현.

| | 문단 사이 43곳 중 0px | 간격 |
| --- | --- | --- |
| 고치기 전 | 43곳 | 전부 0 |
| 고친 뒤 | 0곳 | 8~22px, 중간값 18px |

**남은 확인** — 티스토리 에디터가 저장할 때 `!important` 를 지우지 않는지는 실제로 붙여봐야 안다.
지워지면 다음 안: 문단을 `<div>` 로 낸다 (그 규칙은 `p` 에만 걸린다).

### 2026-09-11 발행본에서 확인 — 에디터가 !important 를 지운다

실제 발행 글(moneyweather.tistory.com/4) HTML 을 받아서 봤다.

```html
원고    <p style="margin:0 0 18px !important">
발행본  <p style="margin: 0 0 18px;" data-ke-size="size16">   ← !important 가 사라짐
```

**인라인 !important 안은 실패했다.** 글 쪽에서는 티스토리 규칙을 이길 방법이 없다.

**해결 — 스킨에서 한다** (글 쪽 여백 값은 건드리지 않는다)

* `MAINSKIN/skin.html` 스크립트가 본문의 `.tt_article_useless_p_margin` 클래스를 떼어낸다.
  규칙이 안 걸리니 원고(md2html)가 정한 인라인 여백이 그대로 산다
* 같이 찾은 것 — 에디터가 그림을 `<p>` 안에 넣어 저장해서 그림 뒤에 빈 `<p></p>` 가 생긴다.
  스타일에 띄어쓰기도 넣는다 (`text-align: center`). 스킨 CSS 로 빈 문단은 숨기고,
  캡션은 `text-align` 까지만 보고 잡는다
* 글 밑 회색 블로그 소개 카드는 `.tt_box_namecard` (티스토리가 JS 로 넣음). 스킨에서 모양을 바꿨다

**검증** — 발행본 HTML 에 새 스킨 CSS·스크립트를 입혀 헤드리스 크롬으로 확인.
문단 사이 여백 살아남, 그림 끝 → 캡션 12px(CSS) · 캡션 → 다음 문단 30px.

**남은 확인** — 새 `skin.html` · `style.css` 를 티스토리에 붙여넣은 뒤 실제 화면에서 한 번 더 본다.
