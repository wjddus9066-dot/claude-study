## 01_썸네일 — 목록에서 클릭을 만드는 것

```text
소스: 04_이미지/2026-09-07_ISA_직장인_실제혜택_v3/_소스/01_썸네일.html
배지: 투자
제목: 다들 만들라는 ISA, 내 세금은 「얼마나 줄어들까?」
말풍선: 주식만 하는데 나도 만들어야 하나…?
일러스트: 바구니(ISA)에 담기는 동전 + 줄어드는 화살표
```

CLAUDE.md §41.2를 따랐다.

| 규칙 | 이 썸네일에서 |
| --- | --- |
| 제목과 **같은 뜻, 다른 문장** | 「뭐가 좋은」 → 「얼마나 줄어들까」. 묻는 말을 바꿨다 |
| 말풍선은 **되묻기** | 4장의 반전(국내 주식은 원래 비과세)을 건드리되 답은 주지 않는다 |
| 답을 다 주지 않는다 | 「누구에게 얼마나」는 본문에서만 |
| 본문에 없는 숫자 금지 | 숫자를 아예 넣지 않았다 |
| 로고 금지 | 온도계는 파비콘이다. 넣지 않았다 |
| 320px에서 읽히는가 | 제목 98px, 말풍선 42px. 일러스트가 화면의 3분의 1 |

## 02_세금비교 — 같은 500만원, 갈리는 세금

막대 높이가 금액에 비례한다. 77만원과 9만 9천원의 차이를 눈으로 보게 하는 게 목적이다.
축 단위·「단순 계산」 전제·출처를 그림 안에 넣었다 (§40).
위치: 2장 계산 코드블록 뒤.

## 03_손익통산 — 그냥 계좌 vs ISA

손익통산은 말로는 잘 안 와닿는다. 같은 입력(A +300 / B −100)을 두 칸에 놓고
계산 경로가 갈리는 걸 보여준다.
위치: 3장 「46만 2천원이 갈립니다」 뒤.

## 04_떠도는숫자 — 인터넷 숫자 vs 현행

왼쪽(미시행)은 점선 테두리에 흐린 글자, 오른쪽(현행)은 실선에 또렷한 글자.
아래 시간 순서 줄이 왜 이런 혼선이 생겼는지 설명한다.
위치: 6장 비교 표 뒤.
