# 본문에 쓴 계산 — 과정을 숨기지 않는다 (CLAUDE.md §17)

전부 **세금만 비교한 단순 계산**이다. 수수료·거래비용은 넣지 않았고 본문에도 그렇게 밝혔다.

## CALC-001 한 해에 500만원을 벌었을 때

```text
그냥 계좌    5,000,000 × 15.4%  = 770,000원   → 77만원
ISA 일반형   200만원 비과세
             3,000,000 × 9.9%   = 297,000원   → 29만 7천원
ISA 서민형   400만원 비과세
             1,000,000 × 9.9%   =  99,000원   → 9만 9천원
```

검산: 5,000,000×0.154=770,000 ✓ / 3,000,000×0.099=297,000 ✓ / 1,000,000×0.099=99,000 ✓
그냥 계좌와 서민형의 차이 770,000−99,000=671,000 → 본문 「67만원」 ✓

## CALC-002 손익통산 (국내 상장 해외 ETF 두 개)

전제: A 이익 300만원, B 손실 100만원. 국내 상장 해외 ETF는 매매차익도 배당소득으로 과세된다 (NUM-001 출처)

```text
그냥 계좌    3,000,000 × 15.4% = 462,000원   → 46만 2천원 (B의 손실은 빠짐)
ISA          300만원 − 100만원 = 200만원 → 비과세 한도 안 → 0원
```

검산: 3,000,000×0.154=462,000 ✓

## CALC-003 만기자금 3,000만원을 연금계좌로 옮겼을 때

```text
30,000,000 × 10% = 3,000,000원  (세액공제 대상 한도가 이만큼 늘어남, 상한 300만원에 딱 맞음)
총급여 5,500만원 이하  3,000,000 × 16.5% = 495,000원
총급여 5,500만원 초과  3,000,000 × 13.2% = 396,000원
```

검산: 3,000,000×0.165=495,000 ✓ / 3,000,000×0.132=396,000 ✓
본문 FAQ에는 「옮긴 금액의 10%만큼(최대 300만원) 돌려받는 한도가 늘어난다」까지만 쓰고
환급액 계산은 넣지 않았다 — FAQ 답이 길어지면 본문으로 옮기라는 기준(글쓰기톤 §9.5)에 따랐다
