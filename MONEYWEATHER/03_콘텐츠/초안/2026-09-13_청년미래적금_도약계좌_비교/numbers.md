# numbers.md — 핵심 숫자 검증

주제: 청년미래적금, 청년도약계좌와 뭐가 다르고 지금 나도 가입할 수 있을까?
검증: 2026-09-13 (기준일도 2026-09-13)

**본문을 쓰기 전에 이 목록을 먼저 검증했다.** 약칭은 sources.md의 SRC 번호.

---

## NUM-001 청년미래적금 납입한도·기간

- 값: 월 최대 **50만원**(연 600만원), **3년**(36개월) 자유적립식, 만기연장 없음
- 기준일: 2026-09-13 현행
- 출처: SRC-001 「최대 월 납입금 50만원의 자유적립식 적금」 / SRC-006 「월 최대 50만원 (연간 600만원) · 3년(36개월)」 / SRC-003
- 검증상태: VERIFIED (3경로)

## NUM-002 정부 기여금 비율

- 값: 일반형 **6%**, 우대형 **12%** (매월 납입금에 매칭)
- 월 50만원이면: 일반형 3만원, 우대형 6만원 (계산)
- 출처: SRC-001 「일반형 月납입금의 6% / 우대형 月납입금의 12%」 / SRC-006
- 검증상태: VERIFIED (2경로)
- 부가: 서민금융진흥원이 매달 기여금을 지급하고, 원금과 기여금 모두에 이자가 붙는다 (SRC-001 「납입 원금 및 기여금 모두 부리」)

## NUM-003 일반형 소득기준

- 값: 직전연도 총급여 **6,000만원**(종합소득 4,800만원) 이하 또는 연매출 3억원 이하 소상공인 **그리고** 가구 기준 중위소득 **200%** 이하
- 출처: SRC-001 참고2 표 / SRC-006 표
- 검증상태: VERIFIED (2경로)
- 주의: 두 조건 동시 충족. 소득은 **2025년** 확정소득 기준 (SRC-003 QA)

## NUM-004 우대형 대상

- 값:
  - 중소기업 재직자 — 총급여 **3,600만원**(종합소득 2,600만원) 이하 + 가구 중위소득 **150%** 이하
  - 연매출 **1억원** 이하 소상공인 + 가구 중위소득 150% 이하
  - 중소기업 신규 취업자 — **일반형 소득요건**을 충족하고 2025년에 최초 취업해 현재 중소기업 재직
- 출처: SRC-001 「일반형 소득요건을 충족하는 중소기업 신규 취업자는 우대형 분류」 / SRC-006 표 / SRC-003 QA
- 검증상태: VERIFIED (3경로)
- 본문 처리: 신규 취업자의 세부 인정 기준(고용보험 1년 미만)은 본문에 쓰지 않았다. 표에서 「작년에 중소기업에 처음 취업」까지만

## NUM-005 기여금 없이 비과세만 받는 구간

- 값: 총급여 **6,000만원 초과 ~ 7,500만원** 이하(종합소득 4,800만원 초과~6,300만원 이하) + 가구 중위소득 200% 이하
- 출처: SRC-001 「이자 소득세 면제만 적용」 / SRC-006 「기여금 미대상(세제혜택만 부여)」
- 검증상태: VERIFIED (2경로)

## NUM-006 금리

- 값: 「최대 7~8% (기본금리 5%)」, **3년 고정**, 은행별 자율 결정
- 우대금리: 총급여 3,600만원 이하 0.5%p 자동, 만기 3개월 전까지 재무상담 이수 0.2%p
- 출처: SRC-006 「금리 최대 7~8% (기본금리 5%)」 / SRC-001 「3년 고정금리」 / SRC-003 QA 우대금리
- 검증상태: VERIFIED (3경로)
- 본문 처리: 은행별 우대금리 항목은 쓰지 않았다. 「기본금리 5%, 최대 7~8%」까지만

## NUM-007 만기 수령액 예시 (금융위원회 계산)

- 값 (월 50만원 × 36개월, **금리 7% 가정**):
  - 일반형 **2,110만원** = 원금 1,800만원 + 기여금 108만원 + 이자 202만원 → 단리 **13.2%** 적금 효과
  - 우대형 **2,227만원** = 원금 1,800만원 + 기여금 216만원 + 이자 211만원 → 단리 **18.2%** 적금 효과
- 8% 가정: 일반형 2,138만원(14.4%), 우대형 2,255만원(19.4%) — 본문에는 7%만 쓴다
- 출처: SRC-003 본문 각주 / SRC-005 「청년미래적금 만기수령금」 표 (같은 숫자)
- 검증상태: VERIFIED (2경로)
- 셈 확인: 1,800+108+202=2,110 ✓ / 1,800+216+211=2,227 ✓ / 3만원×36=108만원 ✓ / 6만원×36=216만원 ✓
- 주의: 이자 계산은 금융위원회 수치를 그대로 옮겼다. 직접 재계산하지 않았다 (월별 납입 시점·기여금 이자 가정이 공개되지 않음)

## NUM-008 우대형 근속 요건

- 값: 가입부터 만기 한 달 전까지 중소기업 재직 **29개월** 이상, 이직 **2회**까지. 못 채우면 전체 기간 6%로 조정
- 출처: SRC-001 / SRC-003 QA / SRC-006
- 검증상태: VERIFIED (3경로)
- 주의: 소상공인 우대형은 가입 뒤 폐업해도 우대형 유지 (SRC-003 QA). 본문에서 「중소기업 우대형」으로 한정해 썼다

## NUM-009 중도해지

- 값: 일반 중도해지 → 기여금·비과세 **없음**. 특별중도해지 사유(사망·해외이주 / 퇴직 / 사업장 폐업 / 천재지변 / 3개월 이상 입원치료·요양이 필요한 상해·질병) → 유지
- 재가입: 해지 **2개월** 후부터, 기여금 비율 × (36개월 − 기존 가입기간) ÷ 36개월
- 출처: SRC-003 QA 「중도해지가 가능한지?」 / SRC-001 Ⅴ. 기타 · QA 5
- 검증상태: VERIFIED (2경로)
- 법령: 사유 목록은 금융위원회가 「조세특례제한법에 규정된」이라고 적었다. 조문 번호는 확인하지 않았다 → factcheck.md

## NUM-010 청년도약계좌 기본 조건

- 값: **5년**(60개월), 월 최대 **70만원**, 총급여 **7,500만원**(종합소득 6,300만원) 이하 + 가구 중위소득 **250%** 이하, 월 최대 기여금 **3만 3천원**, 이자 비과세
- 신규가입: **2025-12-31**까지 운영 후 종료 (「운영 종료 상품」)
- 출처: SRC-007 서민금융진흥원 안내 / SRC-008 금융위원회 보도자료 「월 최대 … 3만 3천 원까지 증가」
- 검증상태: VERIFIED (2경로)

## NUM-011 같은 50만원일 때 도약계좌 기여금 (계산)

- 값: 총급여 2,400만원 이하 — 40만원 × 6.0% + 10만원 × 3.0% = 2만 4천원 + 3천원 = **월 2만 7천원**
- 계산 근거: SRC-008 「매칭한도(월 40·50·60만 원)를 납입한도(월 70만 원)까지 확대하고, 기존 대비 매칭한도가 확대된 구간에는 매칭비율 3.0%」 + 「(연소득 2,400만 원 이하) 40만원 … 매칭비율 6.0%」
- 교차 확인: 같은 규칙으로 70만원 넣으면 40×6% + 30×3% = 3만 3천원 → SRC-007 「월 최대 3.3만원」과 일치
- 출처: SRC-008 금융위원회 보도자료 / SRC-007 서민금융진흥원 월 최대 3.3만원
- 검증상태: VERIFIED (규칙 원문 + 최댓값 교차확인)
- 본문 처리: **가장 많이 받는 구간(2,400만원 이하)만** 쓴다. 다른 구간 매칭비율(4.6·3.7·3.0%)은 보도자료 표가 그림이라 원문 텍스트로 확인하지 못해 쓰지 않았다

## NUM-012 청년도약계좌 금리 구조

- 값: 가입 후 **3년 고정**, 이후 **2년 변동**
- 출처: SRC-009 금융위원회 「가입후 3년은 고정금리, 이후 2년은 변동금리」 / 서울경제(2026-06) 「3년 고정 끝나자」
- 검증상태: VERIFIED (2경로)

## NUM-013 도약계좌 3년 이상 유지 후 해지

- 값: 3년 이상 유지하면 중도해지해도 **비과세 + 기여금 60%**
- 출처: SRC-008 「조세특례제한법 개정(’25.1.1일 시행) 등에 따라 3년 이상만 가입을 유지하면 부득이하게 중도해지하더라도 비과세 혜택과 기여금을 일부(60%)」 / 정책브리핑 정책포커스 (같은 내용)
- 검증상태: VERIFIED (2경로, 단 금융위원회 설명 기준)
- 주의: 「부득이하게」가 사유 제한인지 법령 조문으로 확인하지 않았다 → factcheck.md 추가 확인. 본문은 「금융위원회 안내 기준」으로 쓴다

## NUM-014 갈아타기 허용 기간

- 출처: SRC-001 「’26.6월 청년미래적금 최초 가입기간에만 허용」 / SRC-002 「최초 가입신청 기간(‘26.6~8월)에 한하여」 / SRC-010

## NUM-016 2027년 예산안의 청년미래적금 개편안

- 값: 일반형(6%) **개인·가구소득 요건 폐지** / 우대형 **12% → 15%** / 지방 중소기업 재직자 **25%** / 「’26년 기존 가입자에도 소급하여 적용할 계획」 / 국회 심의 후 **12월 초 확정 예정**
- 출처: SRC-005 금융위원회 예산안 보도자료 / 금융위원회 「청년 성장단계별 종합투자 추진전략」(2026-08-28, 보도참고 87614 첨부) 「일반형 상품의 소득요건을 폐지하고, 우대형 상품의 지급비율도 상향(12 → 15%)」
- 검증상태: VERIFIED (2경로) — **단, 확정 제도가 아니라 정부 예산안**
- 본문 처리: 📌 박스에 「아직 확정이 아닙니다」를 굵게 붙였다 (§38.5.3)

## NUM-017 2인 가구 가구소득 기준 완화

- 값: 본인과 배우자로 이뤄진 2인 가구 — 일반형 200% → **250%**, 우대형 150% → **200%**
- 출처: SRC-003 QA 「가입자 본인과 배우자로 구성된 2인 가구」 / SRC-006 「맞벌이 2인 가구 … 본인과 배우자 모두 소득금액 확인이 가능한 경우」
- 검증상태: VERIFIED (2경로) — **두 자료의 표현이 다르다.** 금융위 QA는 「2인 가구」, 서민금융진흥원은 「맞벌이 2인 가구(둘 다 소득 확인)」
- 본문 처리: 더 좁은 쪽(서민금융진흥원, 운영기관·최신 조회)을 따라 「둘 다 소득이 있는 부부 2인 가구」로 썼다 → factcheck.md
