## 01_썸네일

```text
배지: 재테크 기초
제목: 도약계좌 끝났다는데, 미래적금은 「뭐가」 「더」 줄까?
말풍선: 나 지금 신청할 수 있는 거야…?
일러스트: 저금통 두 개 — 작은 5칸 저금통(도약) 옆에 3칸 저금통(미래) + 위에서 떨어지는 동전(기여금)
```

| 규칙 (§41.2) | 적용 |
| --- | --- |
| 제목과 같은 뜻, 다른 문장 | 「뭐가 다르고 가입할 수 있을까」 → 「뭐가 더 줄까」. 묻는 말을 바꿈 |
| 말풍선은 되묻기 | 6장(지금은 신청기간 아님)을 건드리되 답을 주지 않는다 |
| 답을 주지 않는다 | 6%·12% 숫자를 넣지 않는다 |
| 가정을 단정으로 쓰지 않는다 | 2,110만원(7% 가정)을 넣지 않는다 |
