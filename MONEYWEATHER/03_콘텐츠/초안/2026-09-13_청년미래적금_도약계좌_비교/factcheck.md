| 2장 | 6%·12%·3만원·6만원·10만원·6천원이 한 문단 (숫자 8개) | 10만원 예시를 빼고 「덜 넣은 달은 덜 붙어요」로 |
| 2장 표 | 소득·가구·중기·소상공인 조건을 한 표에 넣으면 칸이 터진다 | 표는 개인소득만. 가구소득은 표 다음 소제목으로 따로 |
| 3장 첫 문장 | 50만원·3년·7%·2,110·2,227 다섯 개 | 굵은 답은 일반형 하나. 7% 가정과 우대형은 다음 문단 |
| [정답] | 숫자를 넣으면 조건이 잘린다 | 개념(얹어준다·세금 없다)과 판단(지금은 신청기간 아님)만. 숫자는 「3년」 하나 |
| 4장 | 도약계좌 소득구간별 비율(6.0·4.6·3.7·3.0%)을 다 넣으면 표가 된다 | 가장 많이 받는 구간 하나만 계산 박스로. 나머지는 원문 텍스트 미확인이기도 하다 |

## 3. 추가 법령 확인 (§38.5.8)

### 추가 확인 1 — 도약계좌 3년 이상 유지 후 해지
- 확인하지 못한 사항: 「3년 이상 유지 시 중도해지해도 비과세 + 기여금 60%」가 사유 제한 없이 적용되는지. 금융위 문장에 「부득이하게」가 있다
- 현재 확인: 금융위원회 보도자료(1순위, 설명 문장) + 정책브리핑(같은 내용). 조세특례제한법 조문은 보지 않았다
- 현재 처리: 본문에 「금융위원회 안내에 따르면」을 붙였다. 사유 조건은 쓰지 않았다
- 추가 확인: 조세특례제한법 제91조의22(청년도약계좌) 및 시행령 — 국가법령정보센터 원문, 청년도약계좌 누리집 FAQ
- 주의: 조문상 사유 제한이 있으면 5장 문장을 「3년 이상 유지한 뒤 ○○ 사유로 해지하면」으로 고친다

### 추가 확인 2 — 청년미래적금 특별중도해지 사유의 시점 조건
- 확인하지 못한 사항: ISA처럼 「해지 전 6개월 이내 발생」 같은 시점 조건이 있는지
- 현재 확인: 금융위원회 QA 목록(1순위, 「조세특례제한법에 규정된」). 조문은 보지 않았다
- 현재 처리: 사유만 나열하고 「사유마다 인정 기준이 있으니 은행에 먼저 확인」을 붙였다
- 추가 확인: 조세특례제한법 청년미래적금 조문(2026년 신설 조문 번호 확인 필요)과 시행령

### 추가 확인 3 — 2인 가구 기준 완화 대상
- 금융위 6월 QA: 「가입자 본인과 배우자로 구성된 2인 가구(배우자가 청년이 아닌 경우도 포함)」
- 서민금융진흥원 상품안내: 「맞벌이 2인 가구 — 본인과 배우자 모두 소득금액 확인이 가능한 경우」
- 처리: 운영기관의 현재 안내(더 좁은 조건)를 따랐다. 사용자 확인 필요 없음 — 좁게 쓰면 틀린 사람에게 기대를 주지 않는다
- 추가 확인: 청년미래적금 누리집 FAQ 또는 1397

## 4. 틀리게 떠도는 정보 (쓰지 않음)

- 토스뱅크 아티클 「청년미래적금 vs 청년도약계좌」 — 도약계좌 개인소득 6,000만원·중위소득 200%, 기여금 6~12%, 월 최대 8.4만원, 미래적금 비과세 「추진 중」으로 적혀 있다. **서민금융진흥원 안내(7,500만원·250%·월 최대 3.3만원)와 다르다.** 출시 전 작성본으로 보인다
- 「예산 초과 시 개인소득 낮은 순」 — 검색 요약에만 있고 금융위 원문에서 못 찾았다. 쓰지 않았다
