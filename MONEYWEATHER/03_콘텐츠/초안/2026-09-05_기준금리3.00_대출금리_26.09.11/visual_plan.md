## CHART_01 — 코픽스 추이

- 용도: 본문 2장 "지금 적용되는 코픽스는 7월 숫자입니다" 아래
- 유형: 꺾은선 그래프
- 데이터

| 대상월 | 신규취급액기준 COFIX |
| --- | --- |
| 2026년 5월 | 2.90% |
| 2026년 6월 | 3.05% |
| 2026년 7월 | 3.18% |

- Y축: % (2.8~3.3 범위, **0에서 시작하지 않으므로 축 범위를 명시**)
- X축: 대상월
- 주석 표시: 7월 16일 기준금리 인상 지점 / 8월 27일 인상 지점(아직 데이터 없음을 점선으로)
- 필수 표기: 단위(%) / 기간 / 기준(신규취급액기준) / 출처(전국은행연합회) / 공시일
- 금지: 3D 효과, 축 왜곡
- **차트 아래 해석 문장 필수(§19)**: "여기서 봐야 할 건 선이 오르고 있다는 사실보다, 이 선의 마지막 점이 아직 7월이라는 점입니다."
