# questions.md — 독자가 궁금해할 질문

독자 기준: 사회초년생. 경제 공부를 원래 좋아하지 않았고 숫자를 보면 눈이 미끄러진다. (글쓰기톤 §2)

---

## 실제로 던지는 질문

```text
Q1.  ISA가 뭐야? 예금이야 주식이야?
Q2.  세금을 깎아준다는데, 원래 얼마를 내는 건데?
Q3.  200만원 비과세라는 게 200만원 넣으라는 뜻이야?
Q4.  나는 주식만 하는데 그래도 이득이야?
Q5.  3년 묶인다던데 중간에 돈 필요하면?
Q6.  연 2,000만원? 그만큼 넣을 돈이 없는데 의미가 있나?
Q7.  인터넷에서 4,000만원으로 늘었다던데 진짜야?
Q8.  만기되면 그냥 찾으면 돼?
Q9.  아무나 만들 수 있어? 나이 제한은?
Q10. 계좌 여러 개 만들어도 돼?
Q11. 중개형·신탁형·일임형은 뭘 골라야 해?
```

---

## 어디에 넣었나

| 질문 | 자리 |
| --- | --- |
| Q1 | 1장 |
| Q2 | 2장 앞부분 — 혜택을 이해하려면 기준선이 먼저 필요하다 |
| Q3 | 2장 + FAQ (가장 흔한 오해) |
| Q4 | **4장 — 이 글의 차별화 지점** |
| Q5 | 5장 + FAQ |
| Q6 | 5장 표 |
| Q7 | **6장 — 이 글의 차별화 지점** |
| Q8 | FAQ (연금계좌 전환) |
| Q9, Q10 | FAQ |

## 뺀 것

| 질문 | 이유 |
| --- | --- |
| Q11 계좌 유형 선택 | 이 글에 넣으면 초점이 흐려진다. **다음 글로 분리** (콘텐츠지도에 기록) |
| 「안 만들면 손해?」 | 손해 프레임은 공포 마케팅에 가깝다 (CLAUDE.md §29). 「나한테 얼마나」로 바꿔 다뤘다 |

## 이 글이 답하는 핵심 질문 (CLAUDE.md §9)

| | |
| --- | --- |
| WHAT | ISA는 번 돈에 붙는 세금을 깎아주는 계좌다 |
| HOW MUCH | 500만원 벌었을 때 서민형이면 67만원이 남는다 |
| WHO | 예금 이자·배당·국내 상장 해외 ETF가 많은 사람. 국내 주식만 하면 효과가 작다 |
| WHEN | 3년을 채워야 비과세가 확정된다 |
| WHAT TO DO | 작년 총급여가 5,000만원을 넘는지 확인한다 |
