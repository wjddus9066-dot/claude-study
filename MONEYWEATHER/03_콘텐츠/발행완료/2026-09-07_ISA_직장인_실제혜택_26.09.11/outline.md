# outline.md — 구조

유형: TYPE C (세금·제도 설명형) / 분량 목표: 심층 분석형 3,500~6,000자
흐름은 글쓰기톤 §9를 그대로 따른다.

---

## 제목 후보

| 유형 | 후보 |
| --- | --- |
| 문제해결형 | **ISA, 다들 좋다는데 그래서 나한테 뭐가 좋은 걸까?** ← 채택 |
| 숫자형 | ISA 넣으면 세금이 얼마나 줄까? 500만원 벌었을 때로 계산해봤습니다 |
| 비교형 | 그냥 계좌 vs ISA, 같은 ETF를 담으면 세금이 얼마나 다를까? |

채택 이유 — 검색 의도("ISA 뭐가 좋은지")를 그대로 담으면서 독자의 말투에 가깝다.
「나한테」가 이 글의 핵심(누구에게 효과가 큰지)과 맞는다.

## 뼈대

```text
제목 → 썸네일 → 도입 3문단 → [정답]
 ↓
1. ISA가 뭔가요?                    ← 개념. 바구니
2. 세금이 얼마나 줄어드나요?         ← 15.4% 기준선 → 200/400만원 → 계산 → 그림
3. 손해 본 것도 같이 쳐준다는 게?     ← 손익통산 → 그림
4. 국내 주식만 하는데 효과가 있나요?  ← ★ 반전
5. 3년 묶이나요?                    ← 조건 표
6. 「연 4,000만원」은 사실인가요?     ← ★ 오해 정정 → 그림
7. 그럼 내 경우에는?                ← 독자 대입
 ↓
[문답] → 결론 + [체크] → [안내]
```
