## 2. 라이선스 확인 상태

### 나눔스퀘어라운드 — 확인됨, 문제없음

네이버 나눔글꼴. 개인·기업 모두 무료, 상업적 이용 가능(글꼴 자체 판매만 금지), 재배포 가능.
웹폰트로 쓸 수 있고 CDN도 있다.

```text
https://cdn.jsdelivr.net/gh/innks/NanumSquareRound@master/nanumsquareround.css
```

### 학교안심 알림장 B — 확인됨, 가장 자유로움

**OFL(SIL Open Font License)**이다. 지금까지 확인한 것 중 조건이 가장 없다.

- 상업적 이용 가능
- **웹폰트 가능** (@font-face)
- 임베딩 가능
- 폰트 파일 재배포까지 가능
- 크레딧 표기 의무 없음

한국교육학술정보원(KERIS) 교육저작권지원센터가 배포한다.
폰트 파일은 `MAINSKIN/Font/학교안심 알림장/` 에 있다.

재배포가 허용되므로 **폰트 파일을 티스토리 스킨에 직접 올려서 쓸 수 있다.**
CDN이 죽어도 글씨가 깨지지 않는다. 이게 CDN보다 안전하다.

### 백묵 헤드라인 (Baekmuk Headline) — 확인됨, 문제없음

김정환(1986–2002)이 만든 폰트다. **MIT와 비슷한 라이선스**로,
사용·복사·수정·배포가 모두 허가돼 있다. 상업적 이용에 제한이 없다.

조건이 하나 붙는데, 어디에 붙는지가 중요하다. 원문은 이렇다.

> Permission to use, copy, modify and distribute this font is hereby granted,
> provided that both the copyright notice and this permission notice appear in
> **all copies of the font**, derivative works or modified versions

고지 의무는 **폰트 파일 자체를 복사하거나 배포할 때** 붙는다.
**그 폰트로 만든 이미지에는 해당하지 않는다.**
우리는 폰트 파일을 배포하지 않고 PNG 로고만 올린다.
그래서 **블로그에 백묵 크레딧을 넣을 필요가 없다.**

「Baekmuk Headline」이라는 **이름은 등록상표**다. 글자 모양이 아니라 이름에 붙는 권리라,
로고에 그 이름을 쓰지 않는 한 상관없다.

### Garet — 상업 이용 가능으로 보이나 조건이 있다

Type Forward 제작. 개인·상업 모두 무료라고 나오지만 **두 가지 조건**이 붙는다.

- **Type Forward 크레딧 표기 필요**
- 폰트 파일 자체의 재배포·재판매 금지

배포 사이트마다 조건이 다를 수 있으니 **실제로 받은 곳의 라이선스를 한 번 확인한다.**

다만 Garet은 **로고 이미지 안에만 들어간다.** 웹폰트로 불러올 일이 없어서
웹폰트 조항은 신경 쓰지 않아도 된다. 이미지에 구워진 글자다.

크레딧은 블로그 소개 페이지나 꼬리말에 한 줄 넣으면 된다.

### 강원교육 서체 — 쓸 수 있지만 고르지 않았다

강원특별자치도교육청 배포. 무료이고 **웹 사용이 명시적으로 허용**돼 있다.
출처 표시는 권장이지 필수가 아니고, 서체 자체를 유료로 양도·판매하는 것만 금지된다.

라이선스는 깨끗한데 **제목용으로는 굵기가 부족했다.**
5종 중 제목에 쓸 만한 모두 Bold · 튼튼 · 새음이 서로 잘 구분되지 않고,
본문 나눔스퀘어라운드와도 인상이 비슷해서 제목이 눈에 띄지 않았다.

### 210 합창단 · 210 옥탑방 — 쓸 수 없다

디자인210 무료 폰트다. 두 가지가 걸린다.

- **웹폰트가 무료 범위에서 제외**돼 있고 별도 계약이 필요하다
- 무료 범위가 **개인 비상업**이다. 애드센스를 붙이면 범위 밖이다

로고·이미지에 구워 넣는 것이 되는지는 출처마다 말이 다르고,
**공식 라이선스 페이지가 자동 조회를 막고 있어(403) 원문을 확인하지 못했다.**
확실히 하려면 디자인210 고객센터에 직접 물어야 한다.

> 애드센스 광고가 게재되는 **개인** 블로그입니다.
> 210 옥탑방을 블로그 **로고와 이미지**에 사용해도 되나요? 웹폰트로는 쓰지 않습니다.

**결론: 문의 결과를 기다리지 말고 나눔스퀘어라운드로 바꾼다.**
어차피 제목은 웹폰트여야 해서 210을 못 쓴다. 로고만 210으로 남기면 따로 논다.
그리고 `CLAUDE.md` §66.11은 저작권이 의심되는 이미지를 발행 중단(RED) 조건으로 둔다.

### FB Cham Blue — 살 수 있는 곳을 찾지 못했다

폰트뱅크(FontBank)가 만든 **유료 상업 폰트**다. 무료 폰트가 아니다.

- MyFonts: **판매 중단**(The font is no longer available for purchase)
- Linotype: 상품 페이지가 404

두 경로 모두 막혀서 **정식으로 구입할 방법을 찾지 못했다.**

> **어딘가에서 무료로 받을 수 있다면 그건 정품이 아닐 가능성이 높다.**
> 유료 폰트를 무료 배포 사이트에서 받아 쓰는 것은 저작권 침해다.
> 애드센스를 붙이는 블로그에서는 특히 위험하다 (`CLAUDE.md` §66.11 RED).

설령 구입할 수 있었더라도 **웹폰트 라이선스를 따로 사야 한다.**
유료 폰트의 웹폰트 라이선스는 보통 월간 페이지뷰 기준으로 과금돼서,
블로그가 커질수록 비용이 올라간다. 제목 한 줄에 지불하기에는 비싼 구조다.

**결론: 쓰지 않는다.**

### 나쁜놈 레귤러 — 특정하지 못했다

검색 2회와 디자인210 폰트 목록 직접 조회로도 이 이름을 찾지 못했다.
디자인210 목록(77종)에는 없지만 목록이 일부만 읽혀서 단정하지는 못한다.

**어디서 받은 폰트인지 알아야 확인할 수 있다.**

## 3. 히어로 제목 — 고른 과정

비교 이미지가 세 장 있다.

| 파일 | 내용 |
| --- | --- |
| `시안/글꼴후보.png` | CDN 웹폰트 4종 |
| `시안/글꼴후보2_보유폰트.png` | `Font/` 폴더에 넣어둔 14종 |
| `시안/히어로_알림장체.png` | **최종 선택. 실제 히어로에 얹어본 것** |

### 왜 알림장 B인가

- 굵고 **살짝 좁아서** 두 줄 제목이 야무지게 들어간다
- 본문 나눔스퀘어라운드와 인상이 뚜렷하게 갈린다 (강원교육은 이게 안 됐다)
- 여기어때 잘난체보다 획이 정돈돼 있다. 돈 이야기에 과하지 않다
- 학교안심 둥근미소 B는 자간이 넓어 두 줄이 길어졌다
- 알림장 R은 제목에 쓰기엔 얇다

| | 글꼴 | 인상 |
| --- | --- | --- |
| 1 | **나눔스퀘어라운드 ExtraBold** | 나머지 글씨와 같은 가족. 가장 자연스럽게 붙는다 |
| 2 | **Gmarket Sans Bold** | 각지고 단단하다. 믿음직한 쪽 |
| 3 | **어그로체 Bold** | 획이 굵고 임팩트가 세다. 가장 눈에 띈다 |
| 4 | **Pretendard ExtraBold** | 무난하고 깔끔하다. 개성은 약하다 |

「눈에 띄었으면 좋겠다」는 기준이면 **3번 어그로체**가 가장 강하고,
**2번 지마켓 산스**가 그다음이다.

### 고를 때 볼 것

- 온도계 그림 옆에 놓였을 때 너무 딱딱하지 않은지
- 「재테크」처럼 받침 많은 글자가 뭉개지지 않는지
- 브랜드가 **쉽다 · 친근하다 · 믿을 수 있다**이다.
  너무 장난스러우면 신뢰가 깎이고, 너무 딱딱하면 친근함이 깎인다

### 라이선스는 고른 뒤에 확인한다

4종 모두 **CDN 주소가 살아있는 것만** 넣었다. 생김새 비교용이다.
고른 다음에 상업적 이용과 웹폰트 허용 여부를 확인한다.
1번(나눔스퀘어라운드)만 이미 확인이 끝났다.

### 확인된 CDN 주소

```text

어그로체          https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_2108@1.1/SBAggroB.woff
```

### 넣고 싶었지만 못 넣은 것

**카페24 써라운드**와 **여기어때 잘난체**도 후보로 좋은데 CDN 주소를 찾지 못했다.
눈누(noonnu.cc)에서 그 폰트의 「웹폰트로 사용하기」 코드를 복사해서 주소를 주면
바로 추가해서 다시 뽑을 수 있다.
