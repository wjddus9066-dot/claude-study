# 이미지 준비 목록

`시안/블로그 메인 스킨 전체.png` 를 기준으로 정리했다.

만들어진 파일은 `MAINSKIN/images/` 에 넣는다.
**파일명은 영문 소문자로 쓴다.** 한글 파일명은 티스토리에 올릴 때 주소가 깨질 수 있다.

---

## 1. 레이아웃 기준

시안은 1264px 폭으로 그려져 있다. 이걸 실제 스킨에서는 이렇게 잡는다.

| 항목 | 값 |
| --- | --- |
| 본문 최대 폭 | 1200px |
| 좌우 여백 | 데스크톱 32px / 모바일 20px |
| 카드 | 5장, 사이 간격 20px → **한 장당 224px** |

화면이 좁아지면 카드가 5열 → 3열 → 2열 → 1열로 접힌다.
카드 한 장이 가장 넓어지는 순간은 모바일 1열일 때로 **약 340px**이다.

## 3. 항목별로 알아둘 것

### 1~2. 로고 두 개

지금 있는 원본은 `04_이미지/로고/…(1).png` — **2000×2000, 아이보리 배경**이다.
그대로는 못 쓴다. 두 가지를 고쳐야 한다.

- **배경을 투명하게** — 아이보리가 박혀 있으면 헤더 배경색이 바뀔 때 네모가 드러난다
- **주변 여백을 잘라내고** 로고만 남긴다

그리고 시안을 보면 헤더와 꼬리말의 로고 **모양이 다르다.**

| | 생김새 | 비율 |
| --- | --- | --- |
| 헤더 | 온도계 + 「오늘의 재테크온도」 2줄 + MONEYWEATHER | 가로 2 : 세로 1 |
| 꼬리말 | 온도계 없이 「오늘의 재테크온도」 1줄 + MONEYWEATHER | 가로 3.6 : 세로 1 |

그래서 파일이 두 개다.

### 3. 히어로 일러스트

온도계, 해, 구름, 반짝이, 그리고 `100° 75° 50° 25° 0°` 눈금과 점선까지
**전부 한 장에** 넣는다. 나누면 위치 맞추기가 번거롭고 얻는 게 없다.

### 세로 크기를 미리 정하지 않는다

**가로 1200px에 맞추고, 세로는 그림 비율대로 나오는 대로 둔다.**

캔버스 크기를 먼저 정해놓으면 그림 비율과 안 맞아서 위아래에 빈 공간이 생긴다.
그러면 휴대폰에서 온도계 아래에 이유 없는 빈칸이 생긴다.

**그림 주변 여백을 넣지 않는다.** 그림이 캔버스에 꽉 차게 뽑는다.
배치와 여백은 CSS에서 정한다. 그게 화면 크기에 따라 조절할 수 있는 유일한 방법이다.

배경(아이보리 → 연분홍으로 번지는 그라데이션과 둥근 모서리)은 **넣지 않는다.**
그건 CSS로 만든다. 그래야 화면 폭이 바뀌어도 배경이 늘어나면서 자연스럽게 채워진다.

용량은 **200KB 아래**로 맞춘다. 첫 화면에 뜨는 이미지라 무거우면 로딩이 눈에 띈다.
그림판 수준 압축으로 안 되면 tinypng.com 같은 데 한 번 돌리면 된다.

### 4~9. 카드 썸네일 — 16:9로 간다

시안의 카드 그림은 4:3에 가깝지만 **16:9(800×450)를 권한다.** 이유가 있다.

글마다 만드는 썸네일이 이미 16:9다.

```text
04_이미지/<글폴더>/01_썸네일.png   ← 이미지렌더.js 기본값 1600×900
```

카드도 16:9로 잡으면 글 썸네일이 **잘리지 않고 그대로** 들어간다.
4:3으로 가면 매번 위아래가 잘려서, 썸네일에 글자를 넣었을 때 잘려나간다.

이 6장은 **글에 썸네일이 없을 때 대신 나오는 그림**이다.
글에 썸네일이 있으면 그게 우선이다.

카테고리 5개의 정의는 `00_브랜드/카테고리.md`에 있다.
파일명이 카테고리와 어긋나지 않게 그 문서를 먼저 본다.

카테고리 5개는 `00_브랜드/카테고리.md`에 정의돼 있다.
파일명이 카테고리와 어긋나지 않게 그 문서를 먼저 본다.

### 10. 공유용 대표 이미지

카카오톡에 링크를 붙이거나 검색 결과에 뜰 때 나오는 그림이다.
`1200 × 630`은 카카오·페이스북이 공통으로 쓰는 규격이다.

글마다 대표 이미지가 있으면 그게 먼저 나오고, 없을 때 이게 나온다.
로고 + 「오늘의 재테크온도」 정도면 충분하다.

### 11. 파비콘

브라우저 탭에 뜨는 작은 아이콘이다. 온도계만 크게 넣는다.
**512×512 정사각으로 한 장만 만들면** 거기서 필요한 크기를 뽑아 쓸 수 있다.

16px까지 줄어들기 때문에 글자를 넣으면 안 보인다. 온도계 하나만 넣는다.

## 4. 이미지로 만들지 않는 것

시안에 보이지만 **파일이 필요 없는** 것들이다. 만들지 말자.

| 시안의 요소 | 어떻게 만드나 |
| --- | --- |
| 히어로 둥근 박스와 그라데이션 배경 | CSS |
| 돋보기(검색) 아이콘 | HTML 안에 SVG 직접 작성 |
| 햄버거(≡) 메뉴 아이콘 | 같음 |
| 「최신 글 보기 >」 남색 버튼 | CSS |
| 「더보기 >」 링크 | CSS |
| 카드의 둥근 모서리·그림자 | CSS |
| 큰 제목 「내 재테크 온도는 몇 도일까?」 | **진짜 글자.** 이미지로 만들면 검색에 안 잡힌다 |

아이콘을 이미지 파일로 만들지 않는 이유는, SVG를 HTML 안에 직접 쓰면
업로드할 필요도 없고 CSS로 색을 바꿀 수 있어서다.

## 5. 기본 스킨은 무엇으로 시작하나

**「기본형 #2」에서 시작한다.** 목록에 없으면 반응형 스킨 중 가장 단순한 것.

어차피 `skin.html`과 `style.css`를 통째로 새로 쓴다. 그래서 **시작 스킨의 디자인은
아무 의미가 없다.** 지울 게 적고 반응형 골격이 있는 쪽이 나을 뿐이다.

고를 때 보는 것.

- 반응형인가
- 사이드바가 없거나 끌 수 있는가 (시안에 사이드바가 없다)
- 스킨 전용 자바스크립트에 심하게 얽혀 있지 않은가

### 스킨을 바꾸기 전에 반드시

> 새 스킨을 적용하면 **지금 스킨의 설정이 초기화된다.**
> 스킨 변경 화면에서 지금 쓰는 스킨을 먼저 **「보관」** 한다.

그리고 지금 스킨의 HTML과 CSS를 통째로 복사해서
`MAINSKIN/백업_YYYY-MM-DD/` 에 넣어둔다. 관리화면의 보관과 별개로 하나 더 남기는 것이다.
