# MAINSKIN — 블로그 메인화면 스킨

「오늘의 재테크온도」 티스토리 블로그의 **껍데기**를 만드는 곳이다.

글 내용과는 상관이 없다. 글은 `03_콘텐츠/`에서 쓰고 `05_자동화/생성/md2html.js`가
발행용 HTML로 바꾼다. 여기는 그 글들을 담는 **틀**만 다룬다.

```text
MAINSKIN/          ← 블로그 틀 (메인화면, 목록, 헤더, 사이드바)
03_콘텐츠/          ← 글 내용
04_이미지/          ← 글 안에 들어가는 그림
```

---

## 폴더 구조

```text
MAINSKIN/
├─ README.md
├─ 시안/            ← 디자인 이미지를 여기에 넣는다 (참고용, 티스토리에 안 올라감)
├─ images/          ← 스킨에서 실제로 쓰는 이미지 (로고 등). 티스토리에 업로드한다
├─ skin.html        ← 티스토리 스킨편집 「HTML」 탭에 붙여넣을 내용
└─ style.css        ← 티스토리 스킨편집 「CSS」 탭에 붙여넣을 내용
```

`skin.html`과 `style.css`는 시안을 받은 뒤에 만든다. 아직 없다.

---

## 티스토리에 올리는 방법

티스토리 관리 → **꾸미기 → 스킨 편집 → html 편집**

| 탭 | 여기 파일 |
| --- | --- |
| HTML | `skin.html` |
| CSS | `style.css` |
| 파일 업로드 | `images/` 안의 파일들 |

업로드한 이미지는 스킨 안에서 `./images/파일명` 으로 부른다.

**작업 전에 반드시 지금 쓰는 스킨을 백업한다.** 스킨 편집 화면의 HTML과 CSS를
통째로 복사해서 `MAINSKIN/백업_YYYY-MM-DD/` 에 넣어둔다. 덮어쓰면 되돌릴 수 없다.

## 글 본문과 규칙이 다르다

같은 HTML/CSS인데 넣는 자리에 따라 되는 게 다르다. 헷갈리기 쉬운 부분이다.

| | 스킨 (여기) | 글 본문 (`md2html.js`) |
| --- | --- | --- |
| `<style>` 블록 | **쓸 수 있다** | 못 쓴다 (저장하면 지워진다) |
| 미디어쿼리 | **쓸 수 있다** | 못 쓴다 |
| 색 지정 | `style.css`에서 한 번 | 태그마다 `style=""` |

그래서 본문 HTML을 만드는 `md2html.js`는 태그마다 색을 직접 박는다.
**스킨에서는 그럴 필요가 없다.** CSS 파일에 정상적으로 쓰면 된다.

## 색

색의 최종 기준은 `00_브랜드/색상.md`, 실제 값은 `05_자동화/팔레트.js`에 있다.
로고에서 직접 뽑은 색이고 명도 대비까지 확인해둔 것이다.

스킨에서 색을 새로 만들지 않는다. `style.css` 맨 위에 CSS 변수로 옮겨 적고 그것만 쓴다.

| 역할 | 색 |
| --- | --- |
| 바탕 | 아이보리 `#FEF8F3` / 크림 `#FAF2E8` |
| 글자 | 네이비 `#1A3360` |
| 흐린 글자 | `#5E6E8F` (이보다 흐리게 쓰지 않는다) |
| 링크·강조 | 로즈 `#B94A65` |
| 장식 전용 | 연분홍 `#F492A6` / 노랑 `#F7CE5A` — **글자색으로 쓰지 않는다** |

로고 원본: `04_이미지/로고/`

## 반응형 기준

주요 독자가 20~40대 직장인이고 대부분 휴대폰으로 본다.
**모바일을 먼저 맞추고 데스크톱을 나중에 넓힌다.**

티스토리는 모바일에서 별도의 모바일웹 스킨을 쓰는 설정이 있다.
반응형 스킨 하나로 갈 거라면 관리 → 꾸미기 → **모바일 설정에서 모바일웹 자동 연결을 꺼야**
데스크톱 스킨이 휴대폰에도 그대로 적용된다. 이 설정을 확인하고 시작한다.

## 진행 순서

```text
1. 시안 이미지를 시안/ 에 넣는다
2. 지금 쓰는 스킨을 백업한다
3. 구조를 나눈다 (헤더 / 목록 / 사이드바 / 꼬리말)
4. style.css 를 쓴다 — 팔레트 변수부터
5. skin.html 을 쓴다 — 티스토리 치환자를 넣는다
6. 브라우저에서 확인한다
7. 티스토리에 붙여넣고 실제 화면에서 확인한다
```

5번의 치환자(`[##_..._##]`)는 기억으로 쓰지 않는다.
티스토리 공식 스킨 가이드에서 확인한 것만 쓴다. 이름이 틀리면 그 자리가 그냥 빈칸이 된다.
