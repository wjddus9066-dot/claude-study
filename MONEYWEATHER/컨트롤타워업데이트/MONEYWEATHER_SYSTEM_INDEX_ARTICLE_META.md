## ARTICLE_META의 역할

ARTICLE_META는 각 글의 "콘텐츠별 값"을 관리한다.

관리 항목:
- 제목 후보 / 선정 제목
- 검색 설명
- 기준일
- 카테고리
- 콘텐츠 레벨
- 검색 의도
- 핵심 질문
- 핵심 답변
- 대상 독자
- 핵심 키워드
- 관련 개념
- 내부 링크 후보
- 대표 이미지
- 이미지 역할 / 핵심 메시지
- 제목 평가
- 독자가 얻어가야 하는 것
- 즉시 확인할 행동
- 후속 질문
- 업데이트 상태
- 출처

기존 문서의 규칙을 복사해 넣지 않는다.

## 데이터 연결

```text
ARTICLE_META
   │
   ├── 제목 → 본문 H1 / Tistory 제목
   ├── 검색 설명 → 메타 description 후보
   ├── 기준일 → 본문 안내 / 업데이트 관리
   ├── 카테고리 → Tistory 카테고리
   ├── 레벨 → 콘텐츠지도
   ├── 검색 의도 → SEARCH_MAP
   ├── 핵심 질문 → 제목 / H2 / AEO
   ├── 핵심 답변 → [정답] / 서론
   ├── 관련 개념 → CONTENT_ARCHITECT
   ├── 내부 링크 → 콘텐츠지도
   ├── 대표 이미지 → 썸네일 / 이미지 자동화
   ├── 제목 평가 → 제목 선택 자동화
   ├── 즉시 행동 → 결론 체크리스트
   ├── 후속 질문 → 다음 콘텐츠 후보
   └── 업데이트 상태 → 재검토 대상 탐지
```

---

## 자동화 우선순위

1. META 파싱
2. 제목 후보 생성
3. 제목 평가
4. 검색 설명 생성/검수
5. 기준일 및 업데이트 상태 확인
6. 이미지 메타 확인
7. 내부 링크 후보 확인
8. 후속 질문 → 콘텐츠지도 후보 등록

### 자동화해도 사람이 최종 판단해야 하는 것

- 제목의 실제 검색 질문 일치 여부
- 핵심 답변의 정확성
- 정책/세금/투자 조건의 누락 여부
- 과장 여부
- 독자에게 오해를 만들 수 있는 표현

## 핵심 브랜드 경험

```text
검색
↓
“이게 뭔데?”
↓
쉽게 이해
↓
“지금 무슨 일이야?”
↓
현재 이슈 이해
↓
“그래서 내 돈은?”
↓
실제 금액·생활로 번역
↓
“그래서 뭘 하지?”
↓
오늘 확인할 행동
↓
다음 질문
```

ARTICLE_META는 이 흐름이 한 글에서 끊기지 않도록 관리하는 제작 데이터다.
