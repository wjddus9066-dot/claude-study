# 05_자동화/검수 — 발행 판정

```bash
node 05_자동화/검수/검수.js <draft.md 경로>
```

`factcheck.md` 의 「판정」 줄은 **이 출력으로만 채운다.** 직접 타이핑하지 않는다.
돌리지 않았으면 판정은 없는 것으로 본다.

---

## 왜 만들었나

ISA 글에서 1차 검수 때 스스로 GREEN 을 줬는데, 2·3차에서 결함이 여덟 개 나왔다.
되돌아보니 패턴이 하나였다.

| | 결과 |
| --- | --- |
| `md2html.js` 가 기계로 검사한 것 | 전부 잡혔다 |
| 사람이 산문으로 판단한 것 | 전부 거짓 통과했다 |

`factcheck.md` 1차 기록에 이렇게 적혀 있었다.

```text
| 표 배치 | 3곳, 연달아 나오지 않음 (톤 §2.5) |
```

그때 표는 **네 개**였고 두 개가 붙어 있었다.
파일을 센 게 아니라 `outline.md` 의 계획을 옮겨 적은 것이다.

같은 식으로 「제목 용어 설명」은 제목의 용어 하나만 보고 §7.5 전체를 통과시켰고
(ETF 는 일곱 번 나오는데 쳐다보지 않았다),
「이미지 숫자 = 본문 숫자」는 숫자만 비교하고 이미지 전체가 맞는 것처럼 적었다.

그래서 판정을 사람 손에서 뺐다.

## 검사 아홉 가지

전부 그때 실제로 터진 결함에 대응한다. 일반적인 품질 검사가 아니다.
새 유형이 터지면 그때 추가한다. (CLAUDE.md §47 — 작게 만들고 검증한 뒤 확장)

| 검사 | 등급 | 놓쳤던 것 |
| --- | --- | --- |
| 금지 표현 | RED | 글쓰기톤 §5.1 |
| 고정 뼈대 | RED | [안내] · 마무리 소제목 · [FOOTER] |
| 표 셀 태그 | RED | `<br>` 이 화면에 글자로 나왔다 |
| 용어 확인 | RED | ETF 가 일곱 번 나오는데 설명이 없었다 |
| 본문↔그림 | RED | 그림에만 「종합소득금액」이 있었다 |
| 숫자 중복 | YELLOW | 77만원이 표·계산·그림에 세 번 |
| 마무리 | YELLOW | 마지막 섹션에 숫자가 여덟 개 |
| 표 배치 | YELLOW | 표 두 개가 붙어 있었다 |
| 출처 개수 | YELLOW | 출처 하나로 VERIFIED 를 찍었다 |

RED 하나라도 있으면 종료코드 1. YELLOW 만 있으면 0.

## 원고에 넣는 두 블록

둘 다 HTML 주석이라 발행본에는 나오지 않는다.

### `<!-- 용어확인 -->` — 빠뜨림 방지

`금융용어.txt` 에 있는 말이 본문에 나오면 여기에 적어야 한다. **안 적으면 RED.**

```markdown
<!-- 용어확인
ETF — 1장 끝. 「그 펀드를 주식처럼 사고팔 수 있게 만든 것」
상장 — 4장. 용어를 쓰지 않고 「한국 증시에 올라와 있어서」로 풀었다
원천징수 — 본문에 쓰지 않았다. [출처] 줄에만 나온다
-->
```

**설명이 좋은지는 판정하지 않는다.** 눈으로 읽으면 그냥 지나가는 걸
한 번은 손으로 짚게 만드는 장치다. 「본문에 안 썼다」도 정당한 답이다.

### `<!-- 검수확인 -->` — 판단이 필요한 YELLOW 승인

```markdown
<!-- 검수확인
숫자 중복 — 200·400만원은 표에서 한도 정의, 계산에서 입력값, 그림에서 결과 강조로 역할이 달라 그대로 둔다
-->
```

승인해도 **출력에서 사라지지 않는다.** 「무엇을 왜 넘겼는지」가
원고와 검수 출력에 나란히 남는다. **RED 는 승인할 수 없다.**

## 이 스크립트가 못 하는 것

GREEN 은 "다 됐다"가 아니라 **"이 셋만 남았다"** 는 뜻이다.

1. **렌더링된 화면** — 표 깨짐과 태그 노출은 마크다운에서 안 보였다
2. **출처 원문이 정말 그 말을 하는지** — 잘못 읽으면 스크립트는 모른다
3. **그 분야를 모르는 사람이 이해하는지** — 내용을 아는 사람은 판정할 수 없다

## 새 검사를 추가할 때

**실제로 발행본까지 갈 뻔한 결함이 나왔을 때만** 추가한다.
있으면 좋을 것 같은 검사를 미리 넣지 않는다. 경고가 많아지면 아무도 안 본다.

추가할 때 위 표에 「놓쳤던 것」을 한 줄 적는다.
왜 있는 검사인지 모르면 나중에 지우게 된다.

새 주제를 다루면서 필요한 말이 생기면 추가한다.
