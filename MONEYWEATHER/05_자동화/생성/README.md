# 05_자동화/생성 — 발행용 변환 도구

## md2html.js — 초안 마크다운 → 발행용 HTML

```bash
node 05_자동화/생성/md2html.js <draft.md 경로>
```

두 파일이 만들어진다.

| 파일 | 용도 |
| --- | --- |
| `article.html` | 브라우저에서 바로 보이는 단독 페이지 |
| `article-tistory.html` | Tistory HTML 모드 붙여넣기용 조각 |

발행본에서 자동으로 빠지는 것: 상단 메타 블록(상태/작성일/카테고리), HTML 주석.

---

## 이미지 삽입 — images.json

초안과 같은 폴더에 `images.json`을 두면 그 위치에 그림이 들어간다.

```json
[
  {
    "after": "",
    "src": "../../../04_이미지/썸네일/2026-09-05_....png",
    "alt": "대체 텍스트"
  },
  {
    "after": "<p>그림으로 보면 이렇습니다.</p>",
    "src": "../../../04_이미지/인포그래픽/....png",
    "alt": "대체 텍스트",
    "caption": "그림 아래 설명"
  }
]
```

- `after`가 비어 있으면 글 맨 앞(대표 이미지)
- `after`는 **변환된 HTML에 등장하는 고유 문자열**이다. 본문을 고치면 앵커도 같이 고쳐야 한다
- 앵커를 못 찾으면 `[건너뜀]` 경고가 뜬다. 무시하지 말 것

## 정합성 검사 (자동 실행)

변환할 때마다 아래 두 가지를 검사한다.
**본문만 고치고 이미지를 안 고치는 실수**가 실제로 두 번 나서 만들었다.

### 1. 금지 표현 — `[정합성 경고]`

`00_브랜드/글쓰기톤.md` §5.1의 목록을 읽어서 본문과 이미지 소스를 모두 검사한다.
목록을 고칠 때 이 스크립트는 건드리지 않아도 된다.

```
[정합성 경고]
  X 본문에 금지 표현: "쉽게 말하면"
  X 2026-09-05_img03_fixvar.html 에 금지 표현: "정리하면 이렇습니다"
```

### 2. 이미지에만 있는 숫자 — `[확인 필요]`

본문에 없는 숫자가 이미지에 있으면 알려준다.
본문에서 뺀 수치나 주장이 그림에만 살아남는 경우를 잡는다.

```
[확인 필요] 이미지에만 있는 숫자입니다. 본문과 다른 말을 하고 있지 않은지 보세요.
  · 2026-09-05_img03_fixvar.html — 본문에 없는 숫자: 0.41%포인트, 0.5%p
```

**주의**: 그래프 축 눈금처럼 정상인 경우도 걸린다. 자동 판단이 아니라 사람이 보라는 알림이다.

### 검사 대상 찾는 방법

초안 폴더 이름의 날짜(`2026-09-05_...`)로 `04_이미지/_소스/2026-09-05_*.html`을 찾는다.
그래서 **이미지 소스 파일명은 반드시 글과 같은 날짜로 시작**해야 한다.

출처 표기줄(`<div class="src">`)은 검사에서 제외한다.
본문은 쉽게 쓰더라도 **출처는 정확해야 하기 때문**이다 (CLAUDE.md §28, §49).

## 알아둘 것

### 이미지를 다시 만들 때

Chrome 헤드리스가 **한글 경로에 `--screenshot` 쓰기를 조용히 실패**한다.
에러도 안 나고 예전 파일이 그대로 남으므로, 임시 경로에 만든 뒤 복사해야 한다.

```bash
CH="/c/Program Files/Google/Chrome/Application/chrome.exe"
TMP="<스크래치패드 경로>"
cp 04_이미지/_소스/2026-09-05_img02_path.html "$TMP/x.html"
"$CH" --headless --disable-gpu --hide-scrollbars --window-size=1600,900 \
      --screenshot="$TMP/x.png" "file:///$(cygpath -m "$TMP/x.html")"
cp "$TMP/x.png" 04_이미지/인포그래픽/2026-09-05_기준금리_전달경로.png
```

만든 뒤에는 **반드시 눈으로 확인**한다. 파일 크기만 보면 안 바뀐 걸 못 잡는다.

### 코드블록의 특수문자

①②③ 같은 동그라미 숫자는 고정폭 폰트에서 깨진다.
`[1단계]` 처럼 쓰는 게 안전하다.

### Tistory에 붙여넣을 때

`article-tistory.html`의 이미지 경로는 로컬 상대경로라 Tistory에서 작동하지 않는다.
붙여넣은 뒤 깨진 이미지 자리에 에디터로 직접 업로드해야 한다.
위치와 캡션은 이미 잡혀 있으므로 파일만 갈아끼우면 된다.

## 색은 어디서 오나

브랜드 색은 `md2html.js` 안의 `C` 객체 한 곳에만 있다. (`00_브랜드/색상.md`)

로고 이미지에서 픽셀을 직접 세어 뽑은 색이다.

```text
md2html.js 의 C
        ↓
   ┌────┴─────┐
 STYLE 객체 (요소별 스타일 한 벌)
   ┌────┴─────┐
article.html   article-tistory.html
(<style> 블록)  (태그마다 style="")
```

색을 바꾸려면 `C`만 고친다. **HTML에 색을 직접 적지 않는다.**

### 티스토리는 왜 인라인인가

티스토리 HTML 모드에는 `<style>` 블록을 같이 넣을 수 없다.
넣어도 스킨이 지우거나 스킨 CSS와 충돌한다.

그래서 `inlineStyles()`가 태그마다 `style=""`을 직접 박는다.
붙여넣기만 하면 스킨 설정과 상관없이 같은 모양으로 나온다.

가상요소(`::before`)와 미디어쿼리는 인라인으로 넣을 수 없어서
읽기용 `article.html`에만 들어간다. 체크리스트 네모가 여기 해당한다.

## 앞머리 안내 박스 — [안내]

글 맨 앞(제목 바로 아래)에 넣는 작은 회색 박스다.
`[안내]` 와 `[/안내]` 사이에 쓴 내용이 `<aside class="pre-note">`로 변환된다.

```markdown
[안내]
**읽기 전에 참고해주세요**

이 글의 금리·이자 계산은 이해를 돕기 위한 대략적인 계산입니다.

특정 금융상품의 가입이나 갈아타기를 권유하는 글은 아닙니다.
[/안내]
```

빈 줄로 나눈 문단이 각각 `<p>`가 된다. 첫 줄의 `**굵은 글씨**`가 박스 제목이 된다.

**면책 문구는 글 끝이 아니라 여기에 쓴다.** 끝에 두면 이미 다 읽은 뒤라 읽을 이유가 없다.
글의 고정 뼈대는 글쓰기톤.md §9.5 참고.

## 인라인 출처 (§49.1)

수치·표·그림 바로 아래에 `[출처]`로 시작하는 줄을 넣으면
작은 회색 글씨로 변환된다.

```markdown
| **8월 27일** | **3.00%** |

[출처] 한국은행 기준금리 · 2026년 8월 27일 적용
```

- **링크도 이 줄에 함께 넣는다.** `· [원문 보기](URL)` 형태
- 링크 문구는 「원문 보기」「공시 보기」「기사 보기」처럼 짧게. URL 자체는 노출하지 않는다
- 한 문단에 출처가 여럿이면 슬래시로 구분

**맨 아래에 [자료 원문 링크] 목록을 따로 만들지 않는다.**
인라인에서 이미 다 보여줬는데 또 나열하면 보고서 부록처럼 보인다.
대신 「자료 확인」 세 줄로 끝낸다 (CLAUDE.md §49.2).

통계표 코드 같은 검증 기록은 독자용이 아니다. numbers.md에 남긴다.

## 꼬리말 분리 — [FOOTER]

본문에 `[FOOTER]` 한 줄을 넣으면, 그 아래는 작은 회색 글씨 블록으로 처리된다.

```markdown
...라는 질문에 스스로 답할 수 있게 됩니다.

[FOOTER]

**참고한 자료**

한국은행 · 전국은행연합회 · 국가데이터처
2026년 9월 6일 기준
```

참고한 자료와 기준일을 여기 넣는다. 면책 문구는 [안내] 박스로 앞에 둔다.
**본문의 마지막 문장이 진짜 마지막 문장으로 남게 하기 위한 장치다** (CLAUDE.md §49.3).

없으면 글 끝이 다시 자료집처럼 보인다.
