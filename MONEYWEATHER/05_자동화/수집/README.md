# 05_자동화/수집 — 원자료 수집 도구

## ecos.js — 한국은행 ECOS 오픈API

금리·통화 지표를 **한국은행 원자료에서 직접** 가져온다.
보도자료 PDF를 사람이 열어 대조하던 작업을 대체한다. (CLAUDE.md §2, §28, §32.1)

### 왜 만들었나

한국은행 보도자료 게시판은 자바스크립트 렌더링이라 자동 조회가 막힌다.
2026-09-05 「기준금리 3%」 글 작성 때 다음을 전부 시도했지만 실패했다.

- 보도자료 게시판 직접 조회 → 목록 미노출
- 사이트 내부 검색 → 빈 페이지
- 헤드리스 Chrome DOM 덤프 → AJAX 후행 로딩으로 미포착
- KDI 경제교육·정보센터 → 해당 회차 미등재

ECOS 오픈API는 같은 데이터를 JSON으로 직접 준다. **우회가 아니라 정공법이다.**

---

### 준비

1. https://ecos.bok.or.kr/api/ 에서 인증키 발급
2. `05_자동화/.env` 파일 생성

```
ECOS_API_KEY=발급받은키
```

`.env`는 `.gitignore`에 등록되어 있어 커밋되지 않는다. **키를 소스에 적지 말 것.**

### 사용법

```bash
# 블로그용 금리 지표 일괄 조회 (가장 자주 쓰는 명령)
node 05_자동화/수집/ecos.js snapshot
node 05_자동화/수집/ecos.js snapshot 202607     # 특정 월 기준

# 새 지표를 찾을 때 — 반드시 이 순서로
node 05_자동화/수집/ecos.js tables 물가          # 1) 통계표 코드 찾기
node 05_자동화/수집/ecos.js items 901Y009        # 2) 항목 코드 찾기
node 05_자동화/수집/ecos.js series 901Y009 M 202606 202608 <항목코드>   # 3) 조회

node 05_자동화/수집/ecos.js key100               # 100대 통계지표
```

주기: `A`(년) `S`(반기) `Q`(분기) `M`(월) `D`(일)
시점 형식: 월 `YYYYMM` / 분기 `YYYYQn` / 년 `YYYY` / 일 `YYYYMMDD`

---

### 중요한 함정

**1. 상위 분류코드로는 조회되지 않는다**

`tables` 결과에는 분류 노드와 실제 통계표가 섞여 있다.
실제 조회 가능한 것은 `SRCH_YN=Y`인 leaf 표뿐이다.

```
0000000053  1.3.3. 예금은행 가중평균금리      ← 분류. items 호출하면 INFO-200
121Y006     1.3.3.2.1. 예금은행 대출금리      ← 실제 통계표
```

**2. 고정금리 비중은 대상 범위가 세 가지다**

2026년 7월 기준으로 값이 전부 다르다.

| 항목코드 | 대상 | 값 |
| --- | --- | --- |
| `LN10000` | 주택담보대출 | 31.9% |
| `LH10000` | 가계대출 전체 | 21.0% |
| `LC10000` | 기업대출 | 별도 |

**본문에 쓴 대상 범위와 항목코드가 반드시 일치해야 한다.** (CLAUDE.md §17)

**3. 지표마다 최신 발표월이 다르다**

기준금리는 8월분이 나와 있어도 가중평균금리는 7월분이 최신일 수 있다.
`snapshot` 출력의 "기준월" 열을 항목별로 확인하고, 본문에도 각각 표기한다. (§32.1)

### 확인된 통계표 코드 (2026-09-06 기준)

`snapshot`이 쓰는 코드다. ECOS API로 직접 확인한 값이며 추측이 아니다.

| 통계표 | 내용 | 주요 항목코드 |
| --- | --- | --- |
| `722Y001` | 한국은행 기준금리 및 여수신금리 | `0101000` 기준금리 |
| `121Y002` | 예금은행 수신금리 (신규취급액) | `BEABAA2` 저축성수신 |
| `121Y006` | 예금은행 대출금리 (신규취급액) | `BECBLA01` 대출평균 / `BECBLA03` 가계대출 / `BECBLA0302` 주담대 / `BECBLA030201` 고정형 주담대 / `BECBLA030202` 변동형 주담대 / `BECBLA03051` 일반신용대출 / `BECBLA03041` 전세자금대출 |
| `121Y010` | 고정·변동금리대출 비중 (신규취급액) | `LN10000` 주담대 고정 / `LN20000` 주담대 변동 / `LH10000` 가계 고정 |
| `121Y013` | 예금은행 수신금리 (잔액) | — |
| `121Y015` | 예금은행 대출금리 (잔액) | — |
| `721Y001` | 시장금리 (월·분기·년) | — |
| `817Y002` | 시장금리 (일별) | — |

코드가 바뀌면 `tables` / `items`로 다시 확인하고 이 표를 갱신할 것.
