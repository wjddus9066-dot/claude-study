# 티스토리 발행 순서

글 하나를 실제로 올릴 때 이 순서대로 한다.

`03_콘텐츠/초안/<글폴더>/` 가 준비돼 있다고 가정한다.
아래에서 `<글폴더>` 는 예를 들면 이렇다.

```text
03_콘텐츠/초안/2026-09-05_기준금리3.00_대출금리_반영시점
```

---

## 0. 발행해도 되는 글인지 먼저 본다

`<글폴더>/factcheck.md` 맨 위 판정을 확인한다.

| 판정 | 어떻게 |
| --- | --- |
| **GREEN** | 발행한다 |
| YELLOW | 해당 항목을 해소하고 판정을 고친 뒤 발행한다 |
| RED | 발행하지 않는다 |

판정 줄이 실제 검증 상태와 어긋나 있으면 **판정 줄을 고친다.**
아래 단계들은 GREEN인 글에만 해당한다.

---

## 1. 파일을 새로 만든다

원고를 고쳤다면 반드시 다시 돌린다. 안 돌리면 예전 HTML이 올라간다.

```bash
# 그림 (팔레트를 바꿨거나 이미지 소스를 고쳤을 때만)
node 05_자동화/생성/이미지렌더.js

# 글 — 항상
node 05_자동화/생성/md2html.js <글폴더>/draft.md
```

「정합성 검사: 이상 없음」이 나오는지 본다.
경고가 나오면 본문과 이미지가 서로 다른 말을 하고 있다는 뜻이다. 고치고 다시 돌린다.

---

## 2. 이미지를 티스토리에 올린다

**이 단계를 건너뛰면 이미지가 하나도 안 나온다.**
HTML 안의 이미지 경로는 내 컴퓨터 경로라서, 티스토리에는 그런 파일이 없다.

먼저 무엇을 어떤 순서로 올려야 하는지 확인한다.

```bash
node 05_자동화/생성/이미지주소적용.js <글폴더>
```

파일 경로가 순서대로 나온다. 티스토리 글쓰기 화면을 열고 **그 순서대로** 끌어다 놓는다.
(순서가 중요하다. 본문에서 그 순서로 등장한다.)

---

## 3. 올라간 이미지를 글에 넣는다

티스토리 글쓰기에서 **HTML 모드**로 바꾼다.
이런 게 보인다. 이게 정상이다.

```
[##_Image|kage@.../img.png?credential=...&expires=...|CDM|1.3|{...}_##]
```

`<img src="...">` 가 아니라 티스토리 전용 매크로다.
이미지가 있는 부분을 **통째로 복사**한다. 골라낼 필요 없다.

### 복사한 건 어디에 넣나

**JS 파일을 열어서 붙여넣는 게 아니다.** 명령 뒤에 인자로 넘긴다.

```bash
node 05_자동화/생성/이미지주소적용.js <글폴더> --붙여넣기 '★'
```

`★` 자리에 복사한 내용을 붙여넣는다.

| 규칙 | 이유 |
| --- | --- |
| 작은따옴표 `' '` 로 감싼다 | 복사한 내용 안에 큰따옴표가 들어 있다 |
| 매크로를 그대로 넘긴다 | 주소로 풀면 만료된다 (아래 참고) |

어느 폴더인지, 어떤 순서인지 헷갈리면 `--붙여넣기` 없이 한 번 돌린다.
올릴 순서와 넣을 명령을 그대로 찍어준다.

### 왜 주소로 풀지 않나

매크로 안의 경로는 `https://blog.kakaocdn.net/dna/...` 로 풀면 실제로 열린다.
하지만 그 주소에는 `expires` 가 붙어 있다. 몇 주면 만료된다.
주소를 박아서 발행하면 **얼마 뒤 이미지가 전부 깨진다.**

매크로는 티스토리가 글을 보여줄 때마다 주소를 새로 발급한다. 그래서 그대로 둔다.

### 확인

개수가 맞지 않으면 멈춘다. 순서가 어긋난 채로 발행되는 것보다 낫다.

출력에 **글의 순서**와 **올린 파일명**이 나란히 찍힌다. 좌우가 어긋나면 순서가 틀린 것이다.

`<글폴더>/article-tistory-발행.html` 이 만들어진다.

---

## 4. 본문을 붙여넣는다

티스토리 글쓰기 → **HTML 모드**에서 기존 내용을 **전부 지우고**,
`article-tistory-발행.html` 을 통째로 복사해서 붙여넣는다.

2단계에서 올린 이미지들도 같이 지워진다. 괜찮다.
이미 주소를 가져왔고, 파일은 티스토리 서버에 남아 있다.

## 5. 글 정보를 채운다

`<글폴더>/seo.md` 에 다 적혀 있다. 그대로 옮긴다.

| 티스토리 입력란 | seo.md 항목 |
| --- | --- |
| 제목 | `SEO_TITLE` |
| 카테고리 | `CATEGORY` |

(`04_이미지/<글폴더>/01_썸네일.png` — 번호 순서가 곧 올리는 순서다)

## 6. 미리보기로 확인한다

발행 전에 **미리보기**를 눌러서 본다. 최소한 이 네 가지.

- [ ] 이미지 4장이 다 나오는가
- [ ] 표가 옆으로 잘리지 않는가
- [ ] 맨 앞 「읽기 전에 참고해주세요」 상자가 회색으로 작게 나오는가
- [ ] 맨 끝이 「그래서 오늘 뭘 보면 될까?」 → 참고한 자료 순서인가

### 잘 안 나올 때

| 증상 | 원인 | 어떻게 |
| --- | --- | --- |
| 이미지가 X로 나옴 | 2~3단계를 건너뜀 | 2단계부터 다시 |
| 표가 잘림 | 스킨 본문 칸이 아주 좁음 | 관리 → 꾸미기 → 스킨 편집에서 본문 너비 조정 |
| 양옆 여백이 많음 | 스킨 설정 | 위와 같음. **글 HTML로는 못 바꾼다** |
| 색이 안 먹음 | 붙여넣을 때 HTML 모드가 아니었음 | HTML 모드에서 다시 |

## 7. 발행하고 기록을 옮긴다

발행한 뒤에,

1. `draft.md` 맨 위 `> 상태:` 를 `PUBLISHED` 로 바꾸고 **발행일과 글 주소**를 적는다
2. 글폴더를 `03_콘텐츠/초안/` 에서 `03_콘텐츠/발행완료/` 로 옮긴다
3. `factcheck.md` 의 「다음 검토 필요일」을 달력에 옮겨 적는다
   — 금리·정책 글은 숫자가 낡는다 (§63)

```bash
git add -A
git commit -m "발행: <글 제목>"
git push
```

## 자주 하는 실수

* **원고 고치고 md2html.js를 안 돌림** → 예전 내용이 올라간다
* **`article-tistory.html` 을 그대로 붙여넣음** → 이미지가 안 나온다.
  붙여넣을 파일은 `article-tistory-발행.html` 이다
* **`미리보기.md` 를 붙여넣음** → 이건 깃허브에서 보라고 만든 파일이다
* **이미지를 순서 섞어서 올림** → 그림이 엉뚱한 자리에 붙는다

## 파일이 안 열리거나 깨져 보일 때

### 한글이 깨져 보인다

**파일이 망가진 게 아니다.** 이 저장소의 `.md` 는 전부 UTF-8이다.
한글을 못 읽는 프로그램으로 열어서 그렇게 보이는 것이다.

VS Code로 열면 제대로 보인다. (2026-09-08 설정 완료)

| 설정한 것 | 왜 |
| --- | --- |
| `.md` → VS Code 연결 | 연결된 프로그램이 없어서 아무 앱으로나 열렸다 |
| `files.encoding: utf8` | 자동 추측을 켜두면 CP949로 잘못 잡는다 |
| `files.autoGuessEncoding: false` | 잘못 잡은 채로 **저장하면 파일이 진짜로 망가진다** |
| `미리보기.md` → 미리보기로 열기 | 읽으라고 만든 파일이니 바로 렌더링된 화면으로 |

> **주의**: 메모장이나 한글(HWP)로 `.md` 를 열어서 **저장하지 않는다.**
> 인코딩이 바뀌면서 한글이 실제로 깨진다. 그때는 `git checkout` 으로 되돌려야 한다.

### 어디서 무엇을 보나

| 보고 싶은 것 | 어떻게 |
| --- | --- |
| 글을 읽기 좋게 | `미리보기.md` 더블클릭 (렌더링된 화면으로 열림) |
| 발행될 모습 그대로 | `article.html` 더블클릭 (브라우저에서 열림, 가장 예쁨) |
| 원고를 고치려고 | `draft.md` 를 VS Code에서 열기 |

일반 `.md` 를 VS Code에서 렌더링해 보려면 **Ctrl + Shift + V** 를 누른다.

## 파일이 여러 개인 이유

| 파일 | 어디에 쓰나 |
| --- | --- |
| `draft.md` | **원고.** 글을 고칠 때는 여기만 고친다 |
| `article-tistory-발행.html` | **티스토리에 붙여넣는 것** |
| `article-tistory.html` | 위 파일의 재료. 이미지 주소가 아직 안 들어간 상태 |
| `article.html` | 브라우저에서 완성본을 볼 때 |
| `미리보기.md` | 깃허브에서 이미지까지 같이 볼 때 |

`draft.md` 를 뺀 나머지는 **전부 자동 생성**이다. 직접 고쳐도 다음에 덮어써진다.
