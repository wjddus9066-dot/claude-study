# 티스토리 이미지 매크로 — 아주 쉽게 따라하기

> 그림이 들어간 글을 티스토리에 올릴 때, **그림 주소를 한 번에 갈아끼우는 방법**입니다.
> 컴퓨터를 잘 몰라도 그대로 따라 하면 됩니다.
>
> 전체 발행 순서는 `05_자동화/발행/티스토리_발행순서.md` 를 봅니다.
> 이 문서는 그중 **그림 넣는 부분만** 떼어내 더 천천히 설명합니다.

---

## 0. 먼저 「왜 이걸 해야 하나」

내 컴퓨터에서 만든 글에는 그림 주소가 이렇게 적혀 있습니다.

```html
<img src="../../../04_이미지/2026-09-13_국민참여성장펀드2차_2030/01_썸네일.png">
```

이건 **내 컴퓨터 안의 위치**를 가리키는 말입니다.
티스토리 서버에는 그런 폴더가 없어서, 이대로 올리면 그림 자리가 깨진 네모로 나옵니다.

그래서 이렇게 합니다.

```text
[1] 티스토리에 그림을 올린다      → 티스토리가 그림을 자기 서버에 저장
        ↓
[2] 티스토리가 만들어준 「매크로」를 복사
        ↓
[3] 글 안의 내 컴퓨터 주소를 그 매크로로 바꾼다
```

3번을 **한 번에 해주는 것**이 이 문서의 명령입니다.

---

## 1. 「매크로」가 뭔가요?

티스토리가 그림 하나에 붙여주는 **긴 글자 덩어리**입니다. 이렇게 생겼습니다.

```text
[##_Image|kage@X2Moh/dJMcadDizbW/.../img.png?credential=...&expires=...|CDM|1.3|{"originWidth":1600,"originHeight":900,"style":"alignCenter","filename":"01_썸네일.png"}_##]
```

무섭게 생겼지만 읽을 필요 없습니다. **통째로 복사해서 붙여넣기만** 하면 됩니다.

| 알아두면 좋은 것 | 설명 |
| --- | --- |
| `filename` | 파일 이름이 들어 있습니다. 그래서 순서가 조금 틀려도 제자리를 찾아갑니다 |
| `expires` | 유효기간입니다. **그래서 주소를 직접 쓰면 안 됩니다** (아래 5번) |

---

## 2. 준비 — 어떤 글인가요?

우리 블로그에는 글을 만드는 방식이 두 가지라, 쓰는 명령이 다릅니다.

| 글 종류 | 그림 넣는 명령 |
| --- | --- |
| 원고(`draft.md`)로 만든 글 → `article-tistory.html` | `node 05_자동화/생성/이미지주소적용.js "<글폴더>"` |
| 손으로 쓴 HTML 글 (예: 초보자용 판) | `node 05_자동화/생성/HTML이미지주소적용.js "<HTML 파일 경로>"` |

**둘 다 쓰는 방법은 똑같습니다.** 같은 명령을 두 번 돌립니다.
아래 설명은 손으로 쓴 HTML 기준이고, 원고로 만든 글은 명령만 바꾸면 됩니다.

---

## 3. 차근차근 따라하기

### 1단계 — 명령을 한 번 돌립니다

VS Code에서 터미널을 엽니다. (위쪽 메뉴 `터미널` → `새 터미널`)
아래를 복사해 붙여넣고 엔터를 칩니다.

```bash
node 05_자동화/생성/HTML이미지주소적용.js "03_콘텐츠/초안/2026-09-13_국민참여성장펀드2차_2030/국민참여성장펀드_2차_2030_전면개편_초보자용_최종_HTML_v3_그림포함.html"
```

이렇게 나옵니다.

```text
티스토리에 이 순서로 그림을 올리세요 (7장)

   1. 01_썸네일.png
   2. 03_펀드구조.png
   ...
```

**이때 글폴더 안에 `붙여넣기.txt` 라는 빈 파일이 생깁니다.** 나중에 여기에 붙여넣습니다.

### 2단계 — 티스토리에 그림을 올립니다

1. 티스토리 → **글쓰기**
2. 그림 파일이 있는 폴더를 엽니다 → `04_이미지/2026-09-13_국민참여성장펀드2차_2030/`
3. 파일을 **1단계에서 알려준 순서대로** 글쓰기 화면에 끌어다 놓습니다

> 순서가 조금 바뀌어도 괜찮습니다. 파일 이름으로 맞추기 때문입니다.
> 다만 **7장을 다 올려야** 합니다. 하나라도 빠지면 다음 단계에서 멈춥니다.

### 3단계 — HTML 모드로 바꿔서 복사합니다

글쓰기 화면 **오른쪽 위**에 `기본모드` 라고 적힌 곳을 눌러 **`HTML`** 로 바꿉니다.

화면이 글자투성이로 바뀝니다. 정상입니다.
방금 올린 그림들이 `[##_Image|...]` 라는 덩어리로 보입니다.

**그 덩어리들을 통째로 긁어서 복사(Ctrl+C)** 합니다.
하나씩 골라낼 필요 없습니다. 그림 부분 전체를 한 번에 잡으면 됩니다.

### 4단계 — `붙여넣기.txt` 에 붙여넣습니다

**중요: 명령 파일(`HTML이미지주소적용.js`)에 붙여넣는 게 아닙니다.**

글폴더 안에 있는 이 파일을 엽니다.

```text
03_콘텐츠/초안/2026-09-13_국민참여성장펀드2차_2030/붙여넣기.txt
                                            └── 여기에 붙여넣습니다
```

`#` 으로 시작하는 안내문 **아래에** 붙여넣고 저장(Ctrl+S)합니다.
메모장에 붙여넣는 것과 똑같습니다. `#` 줄은 지우지 않아도 됩니다.

### 5단계 — 같은 명령을 한 번 더 돌립니다

1단계와 **똑같은 명령**입니다. 위 화살표(↑) 키를 누르면 아까 명령이 다시 나옵니다.

```bash
node 05_자동화/생성/HTML이미지주소적용.js "03_콘텐츠/초안/2026-09-13_국민참여성장펀드2차_2030/국민참여성장펀드_2차_2030_전면개편_초보자용_최종_HTML_v3_그림포함.html"
```

이번에는 이렇게 나옵니다.

```text
갈아끼웠습니다 (7장)

  01_썸네일.png  ←  티스토리 매크로
  03_펀드구조.png  ←  티스토리 매크로
  ...

생성: ..._v3_그림포함-발행.html
```

**이름 끝에 `-발행` 이 붙은 새 파일**이 생깁니다. 이게 올릴 파일입니다.

### 6단계 — 붙여넣고 미리보기

1. 티스토리 글쓰기로 돌아갑니다. **HTML 모드인 상태**에서
2. 기존 내용을 **전부 지웁니다** (Ctrl+A → Delete)
   - 아까 올린 그림이 사라져 보여도 괜찮습니다. 매크로가 새 파일 안에 들어 있고, 그림 파일은 티스토리 서버에 남아 있습니다
3. `-발행.html` 파일을 열어 **전체 선택(Ctrl+A) → 복사(Ctrl+C)**
4. 티스토리 HTML 모드에 **붙여넣기(Ctrl+V)**
5. **미리보기**를 눌러 그림이 다 나오는지 봅니다

---

## 4. 자주 나는 실수

| 이런 일이 | 왜 그런가 | 어떻게 |
| --- | --- | --- |
| 「사용법: node ...」만 나옴 | 파일 경로를 안 적었거나 틀렸다 | 경로를 큰따옴표로 감싸서 다시 |
| 「개수가 다릅니다」 | 그림을 덜 올렸거나 복사를 덜 했다 | 티스토리에서 빠진 그림을 마저 올리고 3단계부터 다시 |
| 「매크로에서 못 찾은 그림」 | 티스토리에 올린 파일 이름이 글과 다르다 | 그 그림만 다시 올리고 매크로를 다시 복사 |
| 명령을 돌려도 아무 일이 없음 | `붙여넣기.txt` 에 저장을 안 했다 | 그 파일을 열어 Ctrl+S |
| 붙여넣었는데 그림이 X로 나옴 | `-발행.html` 이 아니라 원래 파일을 붙여넣었다 | 이름에 `-발행` 이 붙은 파일인지 확인 |
| 며칠 뒤 그림이 전부 깨짐 | 매크로 대신 `blog.kakaocdn.net/...` 주소를 넣었다 | 아래 5번 |

---

## 5. 절대 하면 안 되는 것 하나

그림을 올린 뒤 **오른쪽 클릭 → 이미지 주소 복사**로 나오는 주소를 쓰면 안 됩니다.

```text
https://blog.kakaocdn.net/.../img.png?credential=...&expires=1790780399...
                                                     └── 유효기간
```

이 주소에는 **유효기간(expires)** 이 붙어 있어서 얼마 뒤 **그림이 전부 깨집니다.**

`[##_Image|...]` 매크로를 쓰면 티스토리가 글을 보여줄 때마다 주소를 새로 만들어 주기 때문에 깨지지 않습니다.

---

## 6. 끝나고 나면

- `붙여넣기.txt` 는 지워도 됩니다. 다음에 명령이 또 만들어 줍니다.
- 글을 고쳐서 다시 올릴 때는, **원래 파일(`-발행` 이 안 붙은 것)** 을 고치고 5단계 명령을 다시 돌립니다.
  `-발행.html` 을 직접 고치면 다음 번에 덮어써집니다.
- 그림을 새로 만들었다면 티스토리에 **그 그림만 다시 올리고** 3단계부터 다시 합니다.
