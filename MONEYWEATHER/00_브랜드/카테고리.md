# 카테고리

**5개다. 이보다 늘리지 않는다.**

원래 분야를 7개(경제·주식·ETF·부동산·세금·금융·생활재테크)로 잡았는데,
분야를 그대로 카테고리로 쓰면 독자가 고르기 어렵고 글이 적은 칸이 생긴다.
그래서 독자가 찾는 방식대로 5개로 묶었다.

## 2. 어디에 넣을지 헷갈릴 때

한 글이 두 군데에 걸치는 일이 자주 생긴다. 이 순서로 판단한다.

```text
① 독자가 이 글을 찾을 때 무엇을 검색할까?
        ↓
② 그 검색어가 속한 칸에 넣는다
```

자주 헷갈리는 것들을 미리 정해둔다.

| 주제 | 어디로 | 왜 |
| --- | --- | --- |
| ISA·연금저축 같은 **투자용 계좌** | 투자 | 절세가 주제여도 결국 투자하려고 여는 계좌다 |
| 예금·적금·대출·통장 쪼개기 | 재테크 기초 | 투자 이전 단계다 |
| 부동산에 붙는 세금 | 부동산 | 집을 사려는 사람이 찾는다 |
| 기준금리 인하가 **대출에 미치는 영향** | 오늘의 머니온도 | 뉴스 해설이다 |
| 대출 상품을 **고르는 법** | 재테크 기초 | 상품 선택 가이드다 |
| ETF **배당에 붙는 세금** | 투자 | 투자자가 찾는다 |

**한 글은 한 카테고리에만 넣는다.** 두 곳에 걸치면 위 표대로 하나를 고르고,
다른 쪽 글에서 내부 링크로 연결한다 (`CLAUDE.md` §52).

## 3. 주의

### 티스토리에 등록하는 이름과 정확히 같아야 한다

스킨이 카테고리 이름을 그대로 가져다 쓴다.
띄어쓰기 하나만 달라도 썸네일이 안 붙는다.

```text
재테크 기초        ← 「재테크기초」 아님. 사이에 공백 하나
투자
세금
부동산
오늘의 머니온도    ← 「오늘의 머니온도 이야기」 아님
```

### 카테고리를 새로 만들지 않는다

새 주제가 생겨도 다섯 개 안에서 소화한다.
정말 안 맞는 글이 여러 개 쌓이면 그때 다시 생각한다.
글이 서너 개뿐인 카테고리를 만들면 독자가 빈 칸을 밟게 된다 (`CLAUDE.md` §65).
