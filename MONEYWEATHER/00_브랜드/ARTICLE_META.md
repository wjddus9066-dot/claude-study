# ARTICLE_META — 오늘의 재테크온도

> 글 본문과 제작 데이터를 분리하기 위한 콘텐츠 메타데이터 표준.
> 본문 독자에게는 보이지 않으며, Claude Code / VS Code 자동화와 편집 검수에 사용한다.

## 1. 역할

`ARTICLE_META`는 한 편의 콘텐츠를 만들 때 필요한 정보를 한 곳에 모은다.

- 제목 후보와 선정 제목
- 검색 설명
- 기준일 / 업데이트 상태
- 카테고리 / 콘텐츠 레벨
- 검색 의도
- 핵심 질문 / 핵심 답변
- 대상 독자
- 핵심 키워드
- 선행 개념
- 내부 링크 후보
- 대표 이미지 / 썸네일 정보
- 독자가 읽고 얻어야 하는 것
- 읽고 바로 할 행동
- 다음 질문
- 출처

### 단일소스 원칙

`ARTICLE_META`는 위 항목의 **콘텐츠별 값**을 관리한다.

다음 규칙 자체를 ARTICLE_META에서 다시 정의하지 않는다.

| 기준 | 단일 기준 문서 |
|---|---|
| 말투·문장·본문 흐름·마무리 | `00_브랜드/글쓰기톤.md` |
| 콘텐츠 레벨·선행 개념·콘텐츠 구조 | `00_브랜드/CONTENT_ARCHITECT.md` |
| 검색 의도·SEO/AEO/GEO | `00_브랜드/SEARCH_MAP.md` |
| 색상·이미지 스타일 | `00_브랜드/색상.md` |
| 카테고리 | `00_브랜드/카테고리.md` |
| 검수 | `00_브랜드/CONTENT_CHECKLIST.md` |
| 발행 상태·실제 콘텐츠 목록 | `03_콘텐츠/콘텐츠지도.md` |

ARTICLE_META에는 "이 글에 무엇을 적용할지"만 기록한다.

## 3. 제목 데이터 설계

제목은 본문 마지막에 감으로 정하지 않는다.

### 3.1 제목 후보 3개

가능하면 다음처럼 서로 다른 방향으로 만든다.

**TITLE_1 — 가장 자연스러운 검색 질문**
- 실제 독자가 검색창에 넣을 법한 질문
- 가장 먼저 고려

**TITLE_2 — 상황 + 판단**
- 현재 무슨 일이 생겼는지 + 독자가 무엇을 판단해야 하는지

**TITLE_3 — 돈/숫자 결과**
- 얼마, 세금, 금리, 수익, 비용 등 실제 결과가 궁금한 독자를 겨냥

### 3.2 제목 평가

제목을 선택할 때 다음 7개를 5점 만점으로 평가한다.

- 검색 질문 일치도
- 독자 대상 명확성
- 돈과의 연결
- 구체성
- 초보자 이해도
- 클릭 이유
- 과장 없음

총점이 높더라도 정확성이 떨어지거나 본문의 실제 질문과 다르면 사용하지 않는다.

### 3.3 제목에 넣을 것

가능하면 다음 중 2~4개를 자연스럽게 조합한다.

- 핵심 대상
- 핵심 상품/정책/이슈명
- 실제 질문
- 돈과 연결되는 결과
- 시점
- 판단 포인트

### 3.4 제목에 억지로 넣지 않을 것

- 키워드 반복
- 의미 없는 최신/핫/완벽/필수 같은 과장어
- 본문에서 답하지 않는 질문
- 숫자만 나열한 제목
- 전문가처럼 보이기 위한 전문용어

## 4. 검색 설명 데이터

검색 설명은 제목의 반복이 아니다.

기본 구조:

> [무슨 일이 생겼는지] + [누가 읽어야 하는지] + [이 글에서 무엇을 알 수 있는지] + [가장 중요한 판단 포인트]

검색 설명에서도 제목과 마찬가지로 본문에 실제로 없는 내용을 넣지 않는다.

### 예시

```text
추천 제목:
국민참여성장펀드 2차, 2030이라면 가입할까? 얼마까지 넣고 소득공제는 얼마나 받을까?

검색 설명:
국민참여성장펀드 2차가 9월 30일부터 판매됩니다. 처음 듣는 사회초년생도 이해할 수 있도록 국민성장펀드가 무엇인지, 얼마까지 넣을 수 있는지, 소득공제는 무엇인지, 5년 환매금지와 서민 물량은 무슨 뜻인지, 가입 전에 결정세액부터 확인해야 하는 이유를 쉽게 설명했습니다.

기준일:
2026년 9월 13일
```

검색 설명은 검색 유입을 위한 문구이면서 동시에 독자가 "이 글이 나에게 필요한가?"를 판단하는 문구다.

## 5. 초보자 데이터

moneyweather는 "쉽게 쓰기"만으로 끝내지 않는다.

각 글마다 다음을 명시한다.

### 독자가 처음 보는 개념

```text
[용어]
[한 줄 설명]
[이 글에서 필요한 만큼만 설명하는 이유]
```

### 숫자

```text
[숫자]
→ 무엇을 의미하는가
→ 이전과 비교하면 어떻게 달라졌는가
→ 내 돈으로 환산하면 어떤 의미인가
```

### 행동

반드시 한 가지라도 기록한다.

```text
읽고 바로 확인할 행동:
원천징수영수증의 결정세액 확인
```

이렇게 하면 "읽고 이해했다"에서 끝나지 않고 "읽고 판단할 수 있다"로 연결된다.

## 6. 이미지 데이터

대표 이미지는 글의 첫 이미지이므로 별도의 역할을 기록한다.

```text
대표 이미지:
thumbnail.png

이미지 역할:
THUMBNAIL

이미지 핵심 메시지:
가입 전에 결정세액부터 확인해야 할까?
```

본문용 이미지는 다음 중 하나를 선택한다.

- `MONEY_TRANSLATION` — 경제 변화 → 내 돈
- `DATA` — 숫자 변화 / 비교
- `EXPLAIN` — 개념 / 구조
- `CHECKLIST` — 1분 확인
- `COMPARISON` — 조건 비교
- `TIMELINE` — 시행일 / 반영 시차

### ONE SCREEN ONE IDEA

한 이미지에는 한 가지 핵심만 넣는다.

본문 문단을 이미지에 그대로 복사하지 않는다.
이미지를 봤을 때 관계나 숫자 구조가 글보다 빨리 이해되어야 한다.

## 7. 자동화용 상태값

Claude Code가 글을 관리할 수 있도록 다음 상태값을 사용할 수 있다.

```text
META_STATUS:
[DRAFT / REVIEW / PASS / PUBLISHED / NEED_UPDATE]

TITLE_STATUS:
[NEED / CANDIDATES_READY / SELECTED / FIX]

SOURCE_STATUS:
[NEED / COLLECTING / VERIFIED / COMPLETE]

IMAGE_STATUS:
[NEED / PLANNED / CREATED / CHECKED]

INTERNAL_LINK_STATUS:
[NEED / CHECKED / COMPLETE]

UPDATE_STATUS:
[CURRENT / CHECK_REQUIRED / OUTDATED]
```

## 8. 발행 전 최소 PASS 조건

ARTICLE_META만 채웠다고 글이 완성된 것은 아니다.

다음이 모두 충족되어야 한다.

- 선정 제목이 실제 핵심 질문과 일치한다.
- 검색 설명이 본문 내용과 일치한다.
- 기준일이 명시되어 있다.
- 카테고리와 콘텐츠 레벨이 기존 기준에 맞는다.
- 핵심 답변을 본문 초반에 제시할 수 있다.
- 초보자에게 필요한 선행 개념이 확인되어 있다.
- 내부 링크는 발행된 글만 연결한다.
- 대표 이미지의 역할이 명확하다.
- 읽고 바로 할 행동이 적어도 하나 있다.
- 다음 질문이 자연스럽게 이어진다.
- 출처와 최신성 검증 상태가 확인되어 있다.

# 10. 핵심 철학

`ARTICLE_META`는 SEO를 위한 장식 데이터가 아니다.

이 데이터의 목적은 다음 연결을 유지하는 것이다.

```text
검색 질문
↓
제목
↓
왜 읽어야 하는가
↓
핵심 답변
↓
쉬운 설명
↓
숫자
↓
내 돈으로 번역
↓
오늘 확인할 행동
↓
다음 질문
```

moneyweather의 최종 목표는

> **어려운 경제를 같이 공부하면서, 독자가 자기 돈을 이해할 수 있게 해주는 친구.**

이다.
