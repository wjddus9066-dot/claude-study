# 브랜드 색 — 오늘의 재테크온도

로고에서 그대로 뽑아낸 색이다. 눈대중으로 정하지 않았다.

원본: `04_이미지/로고/미니멀 온도계 로고 돈과 재테크 브랜드 (1).png`
추출 방식: 이미지 전체 픽셀을 세어 가장 많이 쓰인 색부터 정렬 (2026-09-06)

## 1. 로고에서 나온 색

| 색 | 코드 | 로고에서 | 로고 내 비중 |
| --- | --- | --- | --- |
| 아이보리 | `#FEF8F3` | 배경 | 93.1% |
| 네이비 | `#1A3360` | 글자, 「오늘의 재테크」 | 3.3% |
| 진네이비 | `#0C2657` | 온도계 외곽선 | 0.4% |
| 연분홍 | `#F492A6` | 온도계 수은, 「온」 | 0.5% |
| 노랑 | `#F7CE5A` | 반짝임 표시 | 0.03% |

로고에서의 비중이 곧 **글에서의 비중**이다.

바탕은 거의 전부 아이보리, 글자는 네이비, 분홍과 노랑은 아주 조금씩만 쓴다.
분홍을 넓게 깔면 로고와 다른 블로그가 된다.

## 2. 실제 사용 팔레트

로고 색만으로는 표·경계선·흐린 글씨를 만들 수 없어서 같은 계열로 몇 개를 파생시켰다.

| 이름 | 코드 | 쓰는 곳 |
| --- | --- | --- |
| `--ivory` | `#FEF8F3` | 페이지 바탕 |
| `--cream` | `#FAF2E8` | 안내 박스, 표 안쪽 |
| `--cream-d` | `#F6EDE2` | 표 머리줄, 코드 블록 |
| `--line` | `#EADFD2` | 모든 경계선 |
| `--navy` | `#1A3360` | 본문 글자, 제목 |
| `--navy-d` | `#0C2657` | 가장 강한 강조 |
| `--muted` | `#5E6E8F` | 출처, 꼬리말, 캡션 |
| `--pink` | `#F492A6` | 장식 (선, 점, 강조 표시) |
| `--pink-bg` | `#FCE9ED` | 분홍 바탕 박스 |
| `--rose` | `#B94A65` | 링크 |
| `--rose-d` | `#C0546E` | 소제목(h3) |
| `--gold` | `#F7CE5A` | 인용문 왼쪽 선 |
| `--gold-bg` | `#FDF6E6` | 인용문 바탕 |

## 3. 명도 대비 — 읽히는지 먼저 확인했다

예뻐도 안 읽히면 소용없다. 흰 바탕 계열에서 본문 글씨는 4.5 이상이어야 한다.

| 조합 | 대비 | 판정 |
| --- | --- | --- |
| 네이비 `#1A3360` / 아이보리 | **11.82** | 통과 |
| 흐린글씨 `#5E6E8F` / 아이보리 | **4.86** | 통과 |
| 흐린글씨 `#5E6E8F` / 크림 | **4.61** | 통과 |
| 링크 `#B94A65` / 아이보리 | **4.71** | 통과 |
| 소제목 `#C0546E` / 아이보리 | 4.21 | 큰 글씨만 통과 (h3 전용) |
| 연분홍 `#F492A6` / 아이보리 | 2.10 | **글자로 쓰지 않는다** |
| 노랑 `#F7CE5A` / 아이보리 | 1.43 | **글자로 쓰지 않는다** |

### 그래서 정한 규칙

* **연분홍과 노랑은 글자색으로 쓰지 않는다.** 선·배경·표시 같은 장식으로만 쓴다.
* 분홍 계열로 글자를 써야 하면 `--rose`(링크)나 `--rose-d`(소제목)를 쓴다.
* 흐린 글씨는 `#5E6E8F`보다 더 흐리게 만들지 않는다. 4.5 아래로 내려간다.

## 4. 쓰지 않는 색

| 색 | 이유 |
| --- | --- |
| 순백 `#FFFFFF` | 아이보리 바탕에서 혼자 튄다. 카드도 크림을 쓴다 |
| 순검정 `#000000` | 네이비를 쓴다 |
| 회색 계열 | 크림 계열 경계선(`--line`)으로 대체한다 |
| 파랑 `#2C5F8F` 등 | 예전 색. 브랜드 색이 아니다 |
| 빨강 | 경고가 필요하면 `--rose`를 쓴다 |

## 5. 어디에 적용돼 있나

이 팔레트는 **`05_자동화/생성/md2html.js` 한 곳에만** 정의돼 있다.

```text
md2html.js 의 PALETTE
        ↓
   ┌────┴────┐
article.html   article-tistory.html
(<style> 블록)   (각 태그 style="")
```

색을 바꾸려면 `md2html.js`의 `PALETTE`만 고치면 두 파일에 동시에 반영된다.
**HTML에 색을 직접 적지 않는다.**

이미지(`04_이미지/_소스/*.html`)는 별도 파일이라 자동 반영되지 않는다.
색을 바꾸면 이미지도 같이 다시 만들어야 한다.
