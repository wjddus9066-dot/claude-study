# 1. 사이트 구조와 신뢰 요소 (옛 CLAUDE.md §65)

## 기본 카테고리

```text
재테크 기초
투자
세금
부동산
오늘의 머니온도
```

**카테고리의 최종 기준은 `00_브랜드/카테고리.md`다.**
각 카테고리가 무엇을 다루는지, 헷갈리는 주제를 어디에 넣는지 그 문서에 있다.

다섯 개다. 늘리지 않는다.

카테고리를 너무 세분화하지 않는다.

콘텐츠가 거의 없는 카테고리는 만들지 않는다.

## 사이트 신뢰 요소

가능하면 다음 페이지를 준비한다.

* 블로그 소개
* 운영자/작성 원칙
* 문의
* 개인정보처리방침
* 이용약관
* 광고/제휴 관련 안내
* 투자·세금 정보에 대한 주의사항

실제 운영 방식과 일치하도록 작성한다.

**가짜 회사·전문가 자격·경력을 만들어내지 않는다.**

# 2. Google AdSense 및 검색 품질 안전장치 (옛 CLAUDE.md §66)

moneyweather는 장기적으로 Google AdSense 승인을 목표로 한다.

따라서 모든 콘텐츠 제작 과정에서 단순히 "글을 작성할 수 있는가"가 아니라,

**독창성 / 유용성 / 신뢰성 / 탐색성 / 저작권 / 정책 준수 / 사용자 경험**

을 함께 고려한다.

단, Google은 특정 게시글 수, 특정 글자 수, 특정 운영기간을 AdSense 승인 공식 하한선으로 보장하지 않는다.

따라서 인터넷에서 알려진 비공식적인 승인 기준을 Google의 공식 기준처럼 취급하지 않는다.

## 2.1. AdSense 최우선 원칙 (옛 §66.1)

다음 조건을 만족하지 못하는 콘텐츠는 발행하지 않는다.

### 반드시 충족

* 독자에게 실질적인 정보 또는 분석 가치를 제공해야 한다.
* 다른 사이트의 내용을 단순 복사하거나 재작성하지 않는다.
* 검색 결과를 짜깁기하여 하나의 글처럼 만들지 않는다.
* AI가 생성한 내용을 사실 확인 없이 발행하지 않는다.
* 주요 사실과 숫자는 출처를 확인한다.
* 가능하면 원출처를 확인한다.
* 글의 핵심 내용은 moneyweather만의 설명·구조·사례·분석을 포함해야 한다.
* 독자가 글을 읽었을 때 다른 사이트의 원문을 다시 찾아보지 않아도 될 정도의 설명 가치를 제공한다.
* 제목과 본문의 내용이 일치해야 한다.
* 과장된 제목으로 클릭을 유도하지 않는다.
* 존재하지 않는 정보나 링크를 만들어내지 않는다.
* 깨진 링크와 잘못된 링크를 방치하지 않는다.
* 사용자에게 혼란을 주는 탐색 구조를 만들지 않는다.

---

## 2.2. 콘텐츠 하한선 (옛 §66.2)

모든 게시글은 최소한 다음 조건을 만족해야 한다.

### A. 정보적 하한선

게시글에는 다음 중 최소 2개 이상의 실질적인 부가가치가 포함되어야 한다.

* 자체적인 쉬운 설명
* 실제 숫자를 활용한 계산 또는 비교
* 구체적인 사례
* 제도 간 비교
* 독자가 판단할 수 있도록 돕는 체크포인트
* 장단점 분석
* 주의사항
* 기존 정보에서 놓치기 쉬운 부분
* 공식 자료를 바탕으로 한 해석
* 독자 상황에 적용한 예시

단순 뉴스 전달이나 원문 요약만으로 끝나는 글은 발행하지 않는다.

---

### B. 원본성 하한선

다음 형태의 콘텐츠는 발행 금지한다.

* 뉴스기사 문장 재작성
* 다른 블로그 글을 문장만 바꿔서 재작성
* 여러 사이트 내용을 단순히 합친 글
* AI가 인터넷 자료를 요약한 것에 불과한 글
* 검색 결과를 이어 붙인 글
* 출처만 많고 자체적인 설명이 없는 글
* 다른 사이트의 표를 그대로 복제한 글
* 다른 사이트의 이미지를 무단으로 사용하는 글

자료는 참고하되 최종 콘텐츠는 moneyweather의 구조와 설명으로 다시 만든다.

---

## 2.3. 글자 수 하한선·상한선 (옛 §66.3)

글자 수는 Google의 공식 AdSense 승인 기준이 아니다.

따라서 글자 수 자체를 승인 조건으로 간주하지 않는다.

다만 moneyweather의 내부 품질관리 기준으로 다음을 사용한다.

### 기본 정보형

권장:

**1,200~2,500자**

적합한 주제:

* 경제 용어
* 금융 개념
* 간단한 제도 설명
* 짧은 뉴스 해설

---

### 일반 분석형

권장:

**2,000~4,000자**

적합한 주제:

* 금리 변화
* ETF 비교
* 세금 제도
* 부동산 정책
* 투자 전략의 장단점
* 금융상품 비교

---

### 심층 분석형

권장:

**3,500~6,000자**

적합한 주제:

* 복잡한 세금 제도
* 부동산 정책 분석
* 여러 금융상품 비교
* 장기 투자 분석
* 여러 자료를 교차검증해야 하는 주제

---

### 중요 원칙

글자 수를 채우기 위해 내용을 반복하거나 불필요하게 늘리지 않는다.

**정보량이 부족한데 글자 수만 늘리는 행위를 금지한다.**

반대로 충분한 가치가 있는 주제를 글자 수 제한 때문에 지나치게 축약하지 않는다.

즉,

**최소 글자 수보다 '충분한 정보 가치'를 우선한다.**

---

## 2.4. 콘텐츠 상한선 (옛 §66.4)

다음과 같은 경우 글을 억지로 길게 만들지 않는다.

* 동일한 내용을 반복하는 경우
* 같은 설명을 표현만 바꿔 반복하는 경우
* 결론이 이미 끝났는데 문단을 계속 추가하는 경우
* SEO 키워드를 반복하기 위해 문장을 늘리는 경우
* 표와 본문에서 같은 내용을 반복하는 경우
* 출처 설명만 지나치게 길어지는 경우
* AI가 의미 없는 문장을 생성한 경우

내용이 충분하면 종료한다.

---

## 2.5. AI 생성 콘텐츠 안전장치 (옛 §66.5)

Claude는 moneyweather의 콘텐츠 생산을 지원할 수 있다.

그러나 다음 과정을 반드시 거친다.

**AI 생성 → 자료 검증 → 사실 확인 → 독창성 확인 → 편집 → 최종 검수**

AI가 작성했다는 이유만으로 발행하지 않는다.

특히 다음을 자동 생성된 상태 그대로 사용하지 않는다.

* 통계
* 주가
* 금리
* 세율
* 세금 계산
* 부동산 가격
* 정책 내용
* 법률 내용
* 금융상품 수익률
* 배당률
* 투자 전망

---

## 2.6. 'AI 냄새' 방지 원칙 (옛 §66.6)

콘텐츠를 기계적으로 대량 생산한 것처럼 보이게 하지 않는다.

다음 표현을 과도하게 반복하지 않는다.

* "오늘은 ~에 대해 알아보겠습니다."
* "결론부터 말씀드리면"
* "쉽게 말해서"
* "정리하면"
* "마지막으로"
* "중요한 것은"
* "여러분의 성공적인 투자에 도움이 되길 바랍니다."

필요한 경우 사용하되 모든 글에서 동일한 패턴을 반복하지 않는다.

문장 구조와 도입 방식에 변화를 준다.

---

## 2.7. 검색 유입을 위한 금지사항 (옛 §66.7)

검색 유입을 목적으로 다음 행동을 하지 않는다.

* 제목에 키워드 과도하게 반복
* 본문에 동일 키워드 반복 삽입
* 의미 없는 FAQ 대량 생성
* 검색어만 나열한 문단
* 관련 없는 키워드 삽입
* 존재하지 않는 정보를 검색 키워드에 맞춰 생성
* 동일한 내용을 여러 키워드로 쪼개서 반복 발행
* 지역명·상품명만 바꾼 유사 문서 대량 생성

---

## 2.8. 클릭베이트 방지 (옛 §66.8)

다음 유형의 제목을 금지한다.

* "이것 모르면 무조건 손해"
* "지금 당장 사야 합니다"
* "99%가 모르는 비밀"
* "정부가 숨기는 사실"
* "무조건 오른다"
* "이것 하나로 부자됩니다"
* "지금 안 하면 평생 후회합니다"

실제 본문이 뒷받침하지 않는 자극적인 표현을 사용하지 않는다.

---

## 2.9. 금융·투자 콘텐츠 추가 안전장치 (옛 §66.9)

moneyweather는 경제·투자 정보를 다루므로 신뢰성을 특히 중요하게 관리한다.

투자 관련 글에는 가능한 경우 다음 요소를 포함한다.

* 기준일
* 데이터 출처
* 수익률 산정 기준
* 위험요인
* 비교 기준
* 투자 대상의 특성
* 예외사항

과거 성과를 미래 수익처럼 표현하지 않는다.

예측을 사실처럼 표현하지 않는다.

특정 금융상품을 무조건적으로 추천하지 않는다.

---

## 2.10. 사이트 전체 AdSense 준비 하한선 (옛 §66.10)

AdSense 신청 전 사이트 전체를 다음 기준으로 점검한다.

### 콘텐츠

* [ ] 독창적인 콘텐츠가 충분히 축적되어 있는가?
* [ ] 여러 글이 실질적인 정보를 제공하는가?
* [ ] 단순 뉴스 복사/재작성 글이 없는가?
* [ ] 얇은 콘텐츠가 과도하게 많지 않은가?
* [ ] AI 생성물을 무검수로 대량 발행하지 않았는가?

### 사이트 구조

* [ ] 카테고리가 명확한가?
* [ ] 메뉴를 쉽게 찾을 수 있는가?
* [ ] 내부 링크가 정상적으로 작동하는가?
* [ ] 깨진 링크가 없는가?
* [ ] 빈 카테고리나 공사 중인 페이지가 과도하게 존재하지 않는가?
* [ ] 방문자가 원하는 정보를 쉽게 찾을 수 있는가?

### 기본 페이지

가능한 경우 다음 기본 페이지를 준비한다.

* [ ] 블로그 소개 / About
* [ ] 문의 / Contact
* [ ] 개인정보처리방침 / Privacy Policy
* [ ] 필요한 경우 이용약관
* [ ] 필요한 경우 광고·제휴 관련 고지

단, 이러한 페이지의 존재 자체가 AdSense 승인을 보장하는 것은 아니다.

## 2.12. AdSense 승인 준비 시 Claude의 역할 (옛 §66.12)

AdSense 신청 전 Claude는 단순히 "신청해도 될 것 같다"고 판단하지 않는다.

다음 항목을 기준으로 사이트 전체를 감사한다.

1. 콘텐츠 독창성
2. 콘텐츠 깊이
3. 콘텐츠 중복
4. 출처 품질
5. 사실 검증
6. 사용자에게 제공하는 실질적 가치
7. 사이트 탐색성
8. 내부 링크
9. 빈 페이지
10. 깨진 링크
11. 저작권 위험
12. 과도한 AI 생성 흔적
13. 과도한 광고성
14. 제목과 본문의 일치 여부
15. 금융정보의 신뢰성
16. 정책·세금 정보의 최신성

문제가 발견되면 신청을 서두르지 않는다.

**발견 → 수정 → 재검수 → 신청**

순서를 따른다.

---

## 2.13. 가장 중요한 AdSense 원칙 (옛 §66.13)

AdSense 승인을 받기 위해 글을 만드는 것이 목적이 아니다.

**좋은 콘텐츠와 좋은 사이트를 만드는 것을 먼저 목표로 하고, AdSense 승인은 그 결과로 따라오도록 한다.**

Google의 공식 기준을 우선하며, 공식적으로 존재하지 않는 '승인 보장 숫자'를 만들어내지 않는다.

# 3. 수익화 운영 기준 — 조사 필요

> **아직 규칙이 아니다.** 아래는 정해야 할 항목의 목록일 뿐이다.
> Google 애드센스 프로그램 정책, 금융 광고 관련 법령(금융소비자보호법 등) 원문을 확인하기 전에는
> 기억이나 일반 지식으로 채우지 않는다 (`CLAUDE.md` §38.5, §54.1).

* 광고 우선순위 — 콘텐츠 신뢰가 먼저
* 광고 위치 — 본문 흐름과 `[정답]` 박스를 가리지 않는 자리
* 광고와 본문의 구분 표시
* 수익과 연결되는 콘텐츠 유형 — 비교·계산·선택 글
* 제휴 링크 기준과 표기
* 금융상품 광고·제휴 시 주의사항
